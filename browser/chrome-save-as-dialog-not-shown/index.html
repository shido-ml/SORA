Chromeでダウンロード時に保存先を聞かれないとき

ファイルは保存されるが『名前を付けて保存』の画面が出ない。ダウンロード設定で毎回保存先を確認する項目を調べ、テストファイルで試します。

公開・更新：2026年10月30日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

ダウンロード設定で毎回保存先を確認する項目を調べ、テストファイルで試します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Chromeの設定を開き『ダウンロード』へ進みます。
  2. 現在の保存先フォルダーと『ダウンロード前に各ファイルの保存場所を確認する』の状態を確認します。
  3. 毎回選びたい場合はその設定をオンにします。

症状を切り分ける

Chromeのダウンロードが成功しているなら通信障害より保存先の設定を確認します。Chromeには既定の場所へ保存する方法と、毎回場所を尋ねる方法があります。設定を変えた後に安全なテストファイルで選択画面を確認し、既存のダウンロード先も把握します。

「ファイルは保存されるが『名前を付けて保存』の画面が出ない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • シークレットウィンドウや別ブラウザでは開けるか
  • 特定サイトだけか、すべてのサイトで起きるか
  • 拡張機能、VPN、セキュリティソフトを止めると変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 保存先確認の設定がオフ
  • 既定のダウンロードフォルダーへ自動保存されている
  • ファイルを保存できない不具合と保存先選択を混同している

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Chromeの設定を開き『ダウンロード』へ進みます。
  2. 現在の保存先フォルダーと『ダウンロード前に各ファイルの保存場所を確認する』の状態を確認します。
  3. 毎回選びたい場合はその設定をオンにします。
  4. 小さな安全なファイルでダウンロードし、保存先選択が表示されるか確かめます。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います同期解除、閲覧データ削除、ブラウザのリセットでは保存済み情報が消える場合があります。削除対象を確認してください。

不審なダウンロードを検証に使わないでください。保存先を変えても以前のファイルは自動で移動しません。共有PCでは個人情報を含むファイルが意図しないフォルダーに残っていないか確認します。
