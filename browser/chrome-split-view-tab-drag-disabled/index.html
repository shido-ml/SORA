Chromeでタブを画面の端へドラッグしても分割表示にならないとき

二つのタブを並べたいがタブを端へ移動しても分割表示にならない。分割表示のドラッグ操作設定を確かめ、メニューからの分割も比較します。

公開・更新：2026年10月26日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

分割表示のドラッグ操作設定を確かめ、メニューからの分割も比較します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. パソコン版Chromeで二つの通常タブを開き、現在のウィンドウ内で試します。
  2. Chromeの設定、デザインで分割表示のドラッグ操作が有効か確認します。
  3. タブのメニューやリンクのメニューから分割表示を開けるか比較します。

症状を切り分ける

Windowsのスナップレイアウトはアプリのウィンドウを並べる機能ですが、Chromeの分割表示は同じブラウザー内の二つのタブを並べます。右クリックなどのメニューから分割できるなら機能自体は使えるため、端へドラッグする設定と操作位置を確認します。

「二つのタブを並べたいがタブを端へ移動しても分割表示にならない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • シークレットウィンドウや別ブラウザでは開けるか
  • 特定サイトだけか、すべてのサイトで起きるか
  • 拡張機能、VPN、セキュリティソフトを止めると変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 端へのドラッグで分割する設定がオフ。
  • 別のOSの画面分割とChrome内の分割表示を混同。
  • 古いバージョンや対象外の画面で操作している。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. パソコン版Chromeで二つの通常タブを開き、現在のウィンドウ内で試します。
  2. Chromeの設定、デザインで分割表示のドラッグ操作が有効か確認します。
  3. タブのメニューやリンクのメニューから分割表示を開けるか比較します。
  4. ドラッグだけが使えない場合は設定を見直し、分割表示自体がない場合はChromeの更新状態を確認します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います同期解除、閲覧データ削除、ブラウザのリセットでは保存済み情報が消える場合があります。削除対象を確認してください。

作業中のタブを閉じたり、保存していないフォームを再読み込みしたりしないでください。画面の並びが変わるだけの操作であることを確認し、会議画面や入力中のページでは先に内容を保存します。
