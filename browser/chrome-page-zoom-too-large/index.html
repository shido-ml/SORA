Chromeのページだけ文字や画像が大きすぎるとき

Chromeのページだけ文字や画像が大きすぎるとき。安全な順番で原因を切り分ける手順と、データを守る注意点を案内します。

公開・更新：2026年10月21日読了目安：5分確認済み：Google Chrome ヘルプ：テキストや画像のサイズを変更する
結論

一つのサイトだけ大きいか、すべてのサイトで大きいかを確認します。Chromeのページズームを標準へ戻し、全画面表示になっている場合はWindowsならF11キーで切り替えます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 別のサイトを開いて同じ倍率か確認する
  2. Chromeの表示倍率を確認し、必要なら100%へ戻す
  3. WindowsではCtrlキーとマイナスキーで縮小し、Macではcommandキーとマイナスキーで試す

症状を切り分ける

ブラウザのツールバーやタブまで大きい場合と、Webページの中身だけが大きい場合を分けてください。WebページだけならChromeのズームが候補です。一つのサイトだけならサイト別の倍率、すべてなら既定の倍率を確かめます。全画面表示は別の切替なので独立して確認します。

「Chromeのページだけ文字や画像が大きすぎるとき」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • シークレットウィンドウや別ブラウザでは開けるか
  • 特定サイトだけか、すべてのサイトで起きるか
  • 拡張機能、VPN、セキュリティソフトを止めると変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • ページのズーム倍率が変更されている
  • 特定サイトだけ別の倍率が保存されている
  • 全画面表示を拡大と取り違えている

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 別のサイトを開いて同じ倍率か確認する
  2. Chromeの表示倍率を確認し、必要なら100%へ戻す
  3. WindowsではCtrlキーとマイナスキーで縮小し、Macではcommandキーとマイナスキーで試す
  4. 全画面表示の場合はWindowsでF11キー、Macでcommand・control・Fキーを確認する

解決しない場合

Chromeの倍率を標準にしても表示が異常な場合は、OSとChromeの版、特定サイトだけかを記録してサポートを確認します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います同期解除、閲覧データ削除、ブラウザのリセットでは保存済み情報が消える場合があります。削除対象を確認してください。

OS全体の表示倍率を変更するとほかのアプリにも影響します。まずChromeのページだけで再現するかを確認してください。読みにくさを解消するためにアクセシビリティ設定を使っている場合は、元の値を控えてから変更します。
