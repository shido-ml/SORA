Chromeの自動字幕が表示されないときの確認手順

動画や音声を再生してもChromeの自動字幕が出ない。Chromeの字幕設定、再生メディア、言語設定を確認し、サイト側の字幕とブラウザーの自動字幕を区別します。

公開・更新：2026年10月25日読了目安：5分確認済み：Google Chromeヘルプ：字幕と翻訳を管理する
結論

Chromeの字幕設定、再生メディア、言語設定を確認し、サイト側の字幕とブラウザーの自動字幕を区別します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 動画に実際の音声があるかを確認し、別の音声コンテンツでも字幕が出ないか比べます。
  2. Chromeの設定でユーザー補助機能を開き、自動字幕が有効か確認します。
  3. 字幕の言語設定と、必要な言語データの準備状態を確認します。

症状を切り分ける

動画サイトの字幕がないだけなのか、Chromeの自動字幕が全く表示されないのかを分けます。字幕の有無を複数の音声素材で比較し、Chrome設定の切替と言語を確認します。音が出ない症状とは異なり、音声自体が再生できるのに文字が出ない場合を対象とします。

「動画や音声を再生してもChromeの自動字幕が出ない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • シークレットウィンドウや別ブラウザでは開けるか
  • 特定サイトだけか、すべてのサイトで起きるか
  • 拡張機能、VPN、セキュリティソフトを止めると変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • Chromeの自動字幕がオフになっている。
  • 対象言語や言語データの設定が合っていない。
  • 音声がない動画やサイト固有の字幕機能と混同している。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 動画に実際の音声があるかを確認し、別の音声コンテンツでも字幕が出ないか比べます。
  2. Chromeの設定でユーザー補助機能を開き、自動字幕が有効か確認します。
  3. 字幕の言語設定と、必要な言語データの準備状態を確認します。
  4. 動画サービス固有の字幕ボタンとは別に、Chromeの字幕表示領域が出るかを再確認します。

解決しない場合

Chrome側の設定と対応言語を確認しても表示されない場合は、Chrome版、OS、再現する音声の種類を記録し、Googleの公式ヘルプを参照します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います同期解除、閲覧データ削除、ブラウザのリセットでは保存済み情報が消える場合があります。削除対象を確認してください。

音声の内容には個人情報が含まれることがあります。自動翻訳や外部の字幕サービスを使う前に、送信先と所属組織の規則を確認してください。字幕には誤変換があり得るため、重要な発言の証拠として原音を確認せずに利用しないでください。
