Chromeで特定サイトに位置情報を許可できないとき

Chromeで特定サイトに位置情報を許可できないとき。安全な順番で原因を切り分ける手順と、データを守る注意点を案内します。

公開・更新：2026年10月21日読了目安：5分確認済み：Google Chrome ヘルプ：位置情報の設定を管理する
結論

Chromeのサイト設定で位置情報の許可を確認します。サイトだけでなくWindowsやMac本体の位置情報がオフの場合もあるため、ブラウザとOSの二段階を分けて調べます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 問題のサイトで位置情報を求める表示が出るか確認する
  2. Chromeのプライバシーとセキュリティからサイトの設定、位置情報を開く
  3. 対象サイトがブロックされているか確認し、必要なサイトだけ許可を見直す

症状を切り分ける

一つのサイトだけ位置情報を取得できないならサイト別の許可を優先します。複数サイトで同じならChromeの既定設定とOS側の設定を確認します。位置情報を許可したのに現在地がずれる場合は、許可できない問題とは別に端末の測位精度を調べてください。

「Chromeで特定サイトに位置情報を許可できないとき」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • シークレットウィンドウや別ブラウザでは開けるか
  • 特定サイトだけか、すべてのサイトで起きるか
  • 拡張機能、VPN、セキュリティソフトを止めると変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • Chromeで対象サイトをブロックしている
  • Chrome全体の位置情報設定が制限されている
  • WindowsまたはMacの位置情報機能がオフ

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 問題のサイトで位置情報を求める表示が出るか確認する
  2. Chromeのプライバシーとセキュリティからサイトの設定、位置情報を開く
  3. 対象サイトがブロックされているか確認し、必要なサイトだけ許可を見直す
  4. OSが位置情報をオフにしていないか確認し、別サイトでも再現するか試す

解決しない場合

OSとChromeの設定を確認しても対象サイトだけ利用できない場合は、サイト名とブラウザの設定状態を記録してサイト運営者へ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います同期解除、閲覧データ削除、ブラウザのリセットでは保存済み情報が消える場合があります。削除対象を確認してください。

位置情報は訪問先に現在地を伝える機能です。必要性とサイトのプライバシーポリシーを確かめ、すべてのサイトへ一括許可することは避けてください。管理端末の設定を無理に解除せず管理者に相談します。
