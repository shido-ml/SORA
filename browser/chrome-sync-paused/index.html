Chromeの同期が一時停止・再ログインを繰り返す

Chromeの同期が一時停止・再ログインを繰り返すときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：Google Chrome Help - Sync
結論

Googleアカウントの再認証と端末上のサイトデータ保持設定を確認し、ローカルデータを消さずに同期を再開します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. プロフィールから本人確認して再ログインする
  2. 終了時にサイトデータを削除する設定を確認する
  3. 同期対象とアカウントのセキュリティ通知を確認する

症状を切り分ける

「Chrome 同期 一時停止」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • シークレットウィンドウや別ブラウザでは開けるか
  • 特定サイトだけか、すべてのサイトで起きるか
  • 拡張機能、VPN、セキュリティソフトを止めると変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 認証期限切れ
  • 終了時のCookie削除
  • アカウント保護・組織ポリシー

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. プロフィールから本人確認して再ログインする
  2. 終了時にサイトデータを削除する設定を確認する
  3. 同期対象とアカウントのセキュリティ通知を確認する
  4. Googleアカウント上にブックマーク等が保存済みか別端末で確認し、同期のリセットはローカルデータを書き出してから行う

解決しない場合

ブックマーク等がクラウドにあるか確認してから同期リセットを検討します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います同期解除、閲覧データ削除、ブラウザのリセットでは保存済み情報が消える場合があります。削除対象を確認してください。

Chromeのブックマークが消えた・表示されない

Chrome右上のプロフィールが保存時と同じか確認し、passwords.google.comまたはGoogleパスワードマネージャーで対象サイトを検索します。見つかるのに自動入力だけ出ない場合はURLと自動入力設定を確認します。

OneDriveの同期が「保留中」のまま進まない

タスクバーのOneDrive雲アイコンを開き、エラー表示と対象ファイルを確認します。Web版にファイルがあるか確かめたうえで同期を一時停止・再開し、容量不足や使用中のファイル、長すぎる名前を順に解消します。
