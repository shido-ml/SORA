WINDOWS CATEGORY

Windows PCのトラブル

更新、サインイン、Wi-Fi、音、動作、画面出力について、30件の症状を掲載しています。答えを先に読み、当てはまる確認から進めてください。

Windows

Windows 11でWi-Fi接続済みなのにインターネットが使えない

ほかの端末が通信できるなら、PC側の保存済みWi-Fi設定、VPN・プロキシ、IP/DNS設定を順に確認します。ネットワークのリセットは再設定が必要になるため最後に行います。

対処手順を見る →Windows

Windows 11でBluetoothのボタンが消えた・オンにできない

クイック設定だけでなく設定画面とデバイスマネージャーを確認し、Bluetoothアダプターの無効化、ドライバー不調、非搭載機種を切り分けます。

対処手順を見る →Windows

Windows 11でマイクが反応しない・声を認識しない

物理ミュート、入力デバイス、Windowsのマイク許可、アプリ側の入力先を順に確認すると原因を切り分けられます。

対処手順を見る →Windows

Windows Helloの顔認証が使えない・認識されない

対応IRカメラ、カメラ権限、顔データ、PINの状態を確認し、顔認証の再登録はPINでサインインできることを確認してから行います。

対処手順を見る →Windows

Windows 11の検索が開かない・結果が表示されない

検索画面だけの停止か、インデックス不調かを分け、Searchプロセスの再起動、検索インデックス設定、更新の順で確認します。

対処手順を見る →Windows

Windows 11のタスクバーが反応しない・固まる

Windowsエクスプローラーを再起動し、更新、常駐アプリ、ユーザープロファイルの順に原因を切り分けます。

対処手順を見る →Windows

Windowsで写真や動画のサムネイルが表示されない

エクスプローラーの表示設定、ファイル形式、OneDriveの実体、サムネイルキャッシュを順に確認します。ファイル本体を削除する必要はありません。

対処手順を見る →Windows

Windows セキュリティが開かない・真っ白になる

Windows更新、別のセキュリティ製品、組織の管理設定、アプリ破損を確認し、保護機能を無効化せずに復旧します。

対処手順を見る →Windows

BitLocker回復キーを突然求められたときの確認方法

画面の回復キーIDを控え、個人のMicrosoftアカウント、職場・学校アカウント、印刷・USB保存を確認します。回復キーを回避する正規手段はありません。

対処手順を見る →Windows

Windows PCがスリープ直後に勝手に復帰する

直前に復帰させたデバイスやタスクを記録で確認し、マウス・LAN・更新の復帰許可を必要な範囲だけ調整します。

対処手順を見る →Windows

Windows PCがスリープから復帰しない・画面が映らない

電源そのものと画面出力を分け、入力操作、ディスプレイ、強制終了の必要性、グラフィックス・電源ドライバーを確認します。

対処手順を見る →Windows

WindowsノートPCが電源接続済みなのに充電されない

充電器の出力、USB-Cポート、バッテリー保護上限、温度を確認し、膨張や異臭がある場合は充電を中止します。

対処手順を見る →Windows

Windows 11の「設定」が開かない・すぐ閉じる

ショートカットからの起動、更新、設定アプリの修復、システムファイルの順に確認し、PCのリセットは最後まで避けます。

対処手順を見る →Windows

Windowsでキーボードを押すと違う文字が入力される

日本語・英語配列、入力言語、NumLock、IMEを確認し、ソフト設定か物理キー故障かを切り分けます。

対処手順を見る →Windows

Windows 11の時計がずれる・時刻を同期できない

自動時刻とタイムゾーン、ネット接続、Windows Timeサービスを確認します。電源を切るたび大きくずれる場合はCMOS電池も疑います。

対処手順を見る →Windows

Microsoft Storeのダウンロードが進まない

ほかのダウンロードを一時停止し、PCの日時と地域、Microsoftアカウント、Windows Updateを確認します。次にwsreset.exeでStoreキャッシュをリセットしてください。

対処手順を見る →Windows

OneDriveの同期が「保留中」のまま進まない

タスクバーのOneDrive雲アイコンを開き、エラー表示と対象ファイルを確認します。Web版にファイルがあるか確かめたうえで同期を一時停止・再開し、容量不足や使用中のファイル、長すぎる名前を順に解消します。

対処手順を見る →Windows

Windows 11でCドライブの空き容量が勝手に減る

設定の「システム」→「ストレージ」で容量を種類別に確認し、一時ファイル、Windows Update、アプリ、OneDriveの順に増えた場所を特定します。先に原因を確認し、システムフォルダーを手作業で削除しないでください。

対処手順を見る →Windows

Windows 11でWi-Fiの項目が消えた・表示されない

PCを再起動し、物理スイッチと機内モードを確認します。Wi-Fi項目自体がない場合は、デバイスマネージャーで無線LANアダプターが無効・エラー・未認識になっていないかを調べます。

対処手順を見る →Windows

Windows 11でスタートメニューが開かない

まずCtrl＋Shift＋Escでタスクマネージャーを開き、Windowsエクスプローラーを再起動します。直らなければPC再起動、Windows Update、システムファイル修復の順に進めます。

対処手順を見る →Windows

Windows 11でブルースクリーンが出て再起動する

最初に停止コードと、表示されていれば原因ファイル名を写真に残します。直前に追加した機器を外し、Windows Updateとデバイスマネージャーを確認してください。同じ停止コードが繰り返す場合は、セーフモードや回復オプションへ進みます。

対処手順を見る →Windows

Windows 11の動作が急に遅くなった

再起動後も遅い場合は、タスクマネージャーでCPU・メモリ・ディスクを多く使う処理を確認します。空き容量不足や更新処理、不要なスタートアップを一つずつ見直してください。

対処手順を見る →Windows

Windows PCから音が出ない

タスクバーのスピーカーからミュートと出力先を確認し、別の音源でも再生できるか試します。全アプリで無音ならWindowsのサウンド診断とドライバー、特定アプリだけなら音量ミキサーを確認します。

対処手順を見る →Windows

Windows PCで2台目のモニターが認識されない

モニター側の入力端子とWindowsの表示モードを先に確認します。別ケーブルや別端子でも映らない場合に、ディスプレイの検出とグラフィックドライバーを調べます。

対処手順を見る →Windows

Windows Updateが0%・100%のまま進まない

更新画面が止まって見えても、まず通信・空き容量・再起動待ちを確認します。通常画面を操作できるなら再起動とWindows Updateのトラブルシューティングを行い、更新中の電源断は避けてください。

対処手順を見る →Windows

WindowsでUSB機器が認識されない

USBハブを外してPC本体の別ポートへ直接接続し、別のPCでも認識するか確認します。機器自体かWindows側かを分けてから、デバイスマネージャーを確認してください。

対処手順を見る →Windows

Windowsで「PINを使用できません」と表示されサインインできない

まずインターネット接続と再起動を確認し、「サインイン オプション」からMicrosoftアカウントのパスワードで入れるか試します。入れた場合は設定からPINを作り直します。

対処手順を見る →Windows

Windowsでエクスプローラーが応答しない・固まる

特定フォルダーだけか、USB機器を外すと直るかを確認してからWindowsエクスプローラーを再起動します。クイックアクセス履歴の消去と更新を試し、同じ場所だけなら保存先の異常を疑います。

対処手順を見る →Windows

Windowsでカメラが見つからない（0xA00F4244）

ノートPCのカメラシャッターやFnキー、外付けカメラのUSB接続を最初に確認します。次にWindowsのカメラアクセスを許可し、デバイスマネージャーでカメラが無効・未認識になっていないかを調べます。

対処手順を見る →Windows

Windowsにサインイン後、画面が真っ黒でカーソルだけ表示される

Windows＋Ctrl＋Shift＋Bでグラフィックドライバーをリセットし、Ctrl＋Alt＋Deleteが開くか確認します。タスクマネージャーを起動できるならexplorer.exeを新しいタスクとして実行します。
