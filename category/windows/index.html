WINDOWS CATEGORY

Windows PCのトラブル

更新、サインイン、Wi-Fi、音、動作、画面出力について、15件の症状を掲載しています。答えを先に読み、当てはまる確認から進めてください。

Windows

Windows Updateが0%・100%のまま進まない

更新画面が止まって見えても、まず通信・空き容量・再起動待ちを確認します。通常画面を操作できるなら再起動とWindows Updateのトラブルシューティングを行い、更新中の電源断は避けてください。

対処手順を見る →Windows

Windows PCで2台目のモニターが認識されない

モニター側の入力端子とWindowsの表示モードを先に確認します。別ケーブルや別端子でも映らない場合に、ディスプレイの検出とグラフィックドライバーを調べます。

対処手順を見る →Windows

WindowsでUSB機器が認識されない

USBハブを外してPC本体の別ポートへ直接接続し、別のPCでも認識するか確認します。機器自体かWindows側かを分けてから、デバイスマネージャーを確認してください。

対処手順を見る →Windows

Windows PCから音が出ない

タスクバーのスピーカーからミュートと出力先を確認し、別の音源でも再生できるか試します。全アプリで無音ならWindowsのサウンド診断とドライバー、特定アプリだけなら音量ミキサーを確認します。

対処手順を見る →Windows

Windows 11の動作が急に遅くなった

再起動後も遅い場合は、タスクマネージャーでCPU・メモリ・ディスクを多く使う処理を確認します。空き容量不足や更新処理、不要なスタートアップを一つずつ見直してください。

対処手順を見る →Windows

Windows 11でWi-Fiの項目が消えた・表示されない

PCを再起動し、物理スイッチと機内モードを確認します。Wi-Fi項目自体がない場合は、デバイスマネージャーで無線LANアダプターが無効・エラー・未認識になっていないかを調べます。

対処手順を見る →Windows

Windowsで「PINを使用できません」と表示されサインインできない

まずインターネット接続と再起動を確認し、「サインイン オプション」からMicrosoftアカウントのパスワードで入れるか試します。入れた場合は設定からPINを作り直します。

対処手順を見る →Windows

Windows 11でブルースクリーンが出て再起動する

最初に停止コードと、表示されていれば原因ファイル名を写真に残します。直前に追加した機器を外し、Windows Updateとデバイスマネージャーを確認してください。同じ停止コードが繰り返す場合は、セーフモードや回復オプションへ進みます。

対処手順を見る →Windows

OneDriveの同期が「保留中」のまま進まない

タスクバーのOneDrive雲アイコンを開き、エラー表示と対象ファイルを確認します。Web版にファイルがあるか確かめたうえで同期を一時停止・再開し、容量不足や使用中のファイル、長すぎる名前を順に解消します。

対処手順を見る →Windows

Windowsでカメラが見つからない（0xA00F4244）

ノートPCのカメラシャッターやFnキー、外付けカメラのUSB接続を最初に確認します。次にWindowsのカメラアクセスを許可し、デバイスマネージャーでカメラが無効・未認識になっていないかを調べます。

対処手順を見る →Windows

Windows 11でスタートメニューが開かない

まずCtrl＋Shift＋Escでタスクマネージャーを開き、Windowsエクスプローラーを再起動します。直らなければPC再起動、Windows Update、システムファイル修復の順に進めます。

対処手順を見る →Windows

Windowsでエクスプローラーが応答しない・固まる

特定フォルダーだけか、USB機器を外すと直るかを確認してからWindowsエクスプローラーを再起動します。クイックアクセス履歴の消去と更新を試し、同じ場所だけなら保存先の異常を疑います。

対処手順を見る →Windows

Microsoft Storeのダウンロードが進まない

ほかのダウンロードを一時停止し、PCの日時と地域、Microsoftアカウント、Windows Updateを確認します。次にwsreset.exeでStoreキャッシュをリセットしてください。

対処手順を見る →Windows

Windowsにサインイン後、画面が真っ黒でカーソルだけ表示される

Windows＋Ctrl＋Shift＋Bでグラフィックドライバーをリセットし、Ctrl＋Alt＋Deleteが開くか確認します。タスクマネージャーを起動できるならexplorer.exeを新しいタスクとして実行します。

対処手順を見る →Windows

Windows 11でCドライブの空き容量が勝手に減る

設定の「システム」→「ストレージ」で容量を種類別に確認し、一時ファイル、Windows Update、アプリ、OneDriveの順に増えた場所を特定します。先に原因を確認し、システムフォルダーを手作業で削除しないでください。

対処手順を見る →
