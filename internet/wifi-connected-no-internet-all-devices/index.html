全端末でWi-Fi接続済みなのにインターネットが使えない

全端末でWi-Fi接続済みなのにインターネットが使えないときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：BUFFALO / Aterm / carrier official support
結論

全端末で同時に使えない場合は端末設定よりONU・ルーター・回線側を優先し、ランプ、障害、配線、再起動順を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. スマホとPCの2台以上で同時に再現するか確認し、可能なら有線LANでも比較する
  2. 回線事業者の障害情報を確認し、ONU・ルーターの型番と異常ランプを記録する
  3. 電源・光・WAN/LANケーブルの外れを目視し、光コネクタは抜いたり覗いたりしない

症状を切り分ける

「全端末 Wi-Fi 接続済み インターネットなし」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 1台だけか、同じ回線の全端末で起きるか
  • 有線とWi-Fi、2.4GHzと5GHzで結果が変わるか
  • ONU・ルーターのランプと回線事業者の障害情報に異常がないか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 回線障害
  • ONU・ルーター・配線不調
  • 接続認証・IPoE設定

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. スマホとPCの2台以上で同時に再現するか確認し、可能なら有線LANでも比較する
  2. 回線事業者の障害情報を確認し、ONU・ルーターの型番と異常ランプを記録する
  3. 電源・光・WAN/LANケーブルの外れを目視し、光コネクタは抜いたり覗いたりしない
  4. 公式手順に従ってONU、ルーターの順に電源を入れ直し、各機器の起動完了を待つ

解決しない場合

異常ランプや全端末障害が続く場合は回線事業者へ連絡します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますルーターの初期化ボタンは押さないでください。接続ID、電話、IPv6などの再設定が必要になる場合があります。
