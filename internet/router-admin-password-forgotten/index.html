Wi-Fiルーターの管理者パスワードを忘れた

Wi-Fiルーターの管理者パスワードを忘れたときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：BUFFALO Support
結論

Wi-Fi接続パスワードと管理者パスワードを区別し、本体ラベル、セットアップカード、保存済み資格情報を確認します。初期化は最後です。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. ログイン画面が求めるものが管理者用かWi-Fi接続用か、画面と機種別マニュアルで確認する
  2. 本体ラベル・セットアップカード・公式アプリの初期ユーザー名とパスワードを確認する
  3. 変更済みならパスワード管理アプリやブラウザーの保存済み資格情報を本人の端末で確認する

症状を切り分ける

「ルーター 管理者パスワード 忘れた」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 1台だけか、同じ回線の全端末で起きるか
  • 有線とWi-Fi、2.4GHzと5GHzで結果が変わるか
  • ONU・ルーターのランプと回線事業者の障害情報に異常がないか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 2種類のパスワードの混同
  • 変更済み管理者パスワード
  • 中古・引継ぎ端末

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. ログイン画面が求めるものが管理者用かWi-Fi接続用か、画面と機種別マニュアルで確認する
  2. 本体ラベル・セットアップカード・公式アプリの初期ユーザー名とパスワードを確認する
  3. 変更済みならパスワード管理アプリやブラウザーの保存済み資格情報を本人の端末で確認する
  4. 不明なままならPPPoE・IPoE・電話設定の控えを作り、メーカー確認後にだけ工場出荷状態へ戻す

解決しない場合

初期化でインターネット設定が消える機種はメーカー・回線事業者へ先に相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますルーターの初期化ボタンは押さないでください。接続ID、電話、IPv6などの再設定が必要になる場合があります。
