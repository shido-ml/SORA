WindowsのSmart App Controlをオンにできないとき

Windowsセキュリティで保護を有効にしたいが操作が使えない。現行の設定画面と管理状態、更新状況を調べ、再有効化の可否を判断します。

公開・更新：2026年10月30日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

現行の設定画面と管理状態、更新状況を調べ、再有効化の可否を判断します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Windowsセキュリティの『アプリとブラウザーコントロール』『Smart App Controlの設定』を開きます。
  2. 現在の状態とWindows Updateの適用状況を確認します。
  3. 会社や学校の管理PC、開発者モード、Sモードの有無を調べます。

症状を切り分ける

Smart App Controlは不明なアプリの実行を評価するWindowsの保護です。過去の案内には再有効化に初期化が必要とありますが、最近のWindows更新ではセキュリティアプリから再有効化できる場合があります。画面の状態と更新状況を最初に確認し、PCを初期化する前に管理要件を調べます。

「Windowsセキュリティで保護を有効にしたいが操作が使えない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • デバイス管理や開発者モードの条件
  • Windowsの更新前で再有効化の操作が表示されない
  • Sモードまたは診断データの設定条件

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Windowsセキュリティの『アプリとブラウザーコントロール』『Smart App Controlの設定』を開きます。
  2. 現在の状態とWindows Updateの適用状況を確認します。
  3. 会社や学校の管理PC、開発者モード、Sモードの有無を調べます。
  4. オンにできる場合は設定を変更し、信頼できるアプリの動作を確認します。管理PCなら管理者へ相談します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

保護が働かない原因を調べるために出所不明の実行ファイルを起動しないでください。初期化はデータ損失を伴うので、この問題だけを理由に安易に実行しません。会社の管理ポリシーを無断で変えないでください。
