Excelの計算で「#VALUE!」が出るとき

Excelで足し算や引き算の式に#VALUE!が表示され、数値の計算結果が出ない。参照セルに数値に見える文字列や空白が混じっていないか、数式の評価で原因箇所を確認します。

公開・更新：2026年11月7日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

参照セルに数値に見える文字列や空白が混じっていないか、数式の評価で原因箇所を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. エラーのセルを選び数式と参照先を確認する
  2. 「数式」タブの「数式の検証」でどの参照値からエラーになるか調べる
  3. 数値のつもりのセルに空白や文字列が含まれていないか確認する

症状を切り分ける

式そのものが誤っている場合と、参照値だけが文字列になっている場合を分けます。エラーを隠す前に原因セルを特定します。 同じアカウントと端末で変更前後を比較し、再現する条件を記録します。設定を一度に複数変えず、結果を見て次の確認に進みます。

「Excelで足し算や引き算の式に#VALUE!が表示され、数値の計算結果が出ない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 数値に見えるセルが実際には文字列である
  • 見えない空白や特殊文字が混じっている
  • 式の演算対象に予期しない型の値がある

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. エラーのセルを選び数式と参照先を確認する
  2. 「数式」タブの「数式の検証」でどの参照値からエラーになるか調べる
  3. 数値のつもりのセルに空白や文字列が含まれていないか確認する
  4. 元データの意味を保ったまま必要な値だけ修正し、計算結果を再確認する

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

IFERRORでエラーを隠すと誤った集計に気づけなくなります。会計や集計の表では元データを勝手に削除せず、修正前のコピーを保存してください。 操作前に対象と影響を確認し、仕事や共有のアカウントでは管理者の方針を優先してください。
