Windows 11でクリップボードの履歴が表示されないとき

Windows 11でクリップボードの履歴が表示されないとき。安全な順番で原因を切り分ける手順と、データを守る注意点を案内します。

公開・更新：2026年10月21日読了目安：4分確認済み：Microsoft サポート：クリップボードの使用
結論

WindowsキーとVキーで履歴を開き、有効化を求める表示があればオンにします。再起動後はピン留め以外の履歴が消える仕様なので、以前の内容が見えないことと機能が動かないことを分けてください。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. WindowsキーとVキーを押し、履歴画面が開くか確認する
  2. 有効化ボタンが表示された場合は内容を読んで履歴をオンにする
  3. 短いテキストを新しくコピーして履歴に追加されるか試す

症状を切り分ける

まず新しい短文をコピーして、履歴に現れるかどうかを確かめます。新規の項目は見えるのに過去の項目だけない場合、再起動や履歴の消去による可能性が高くなります。別のアプリからコピーした内容は見えるかも比較し、一つのアプリに限る問題かを分けます。

「Windows 11でクリップボードの履歴が表示されないとき」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • クリップボード履歴が無効になっている
  • 再起動によってピン留め以外の履歴が消えた
  • コピー自体が成功していない、またはアプリ側で制限されている

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. WindowsキーとVキーを押し、履歴画面が開くか確認する
  2. 有効化ボタンが表示された場合は内容を読んで履歴をオンにする
  3. 短いテキストを新しくコピーして履歴に追加されるか試す
  4. 再起動前にコピーした項目を探している場合は、ピン留めの有無を確認する

解決しない場合

新しいテキストも履歴に出ず、設定を変更できない場合は、管理端末の制限の有無を管理者に確認します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

履歴を一括消去すると保存した項目を失う可能性があります。共有PCでは履歴に個人情報が残る場合もあるため、有効化する前に利用環境を確認してください。消えた履歴の復元を保証するツールは案内しません。
