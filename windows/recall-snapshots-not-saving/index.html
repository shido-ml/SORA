Windows Recallでスナップショットが保存されないとき

Recallを開いても最近の画面履歴が増えない。対応PCと保存スイッチ、一時停止状態を確認して記録条件を切り分けます。

公開・更新：2026年10月30日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

対応PCと保存スイッチ、一時停止状態を確認して記録条件を切り分けます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. PCがRecallに対応するCopilot+ PCか確認します。
  2. 設定の『プライバシーとセキュリティ』『Recallとスナップショット』で保存がオンか確認します。
  3. タスクトレイのRecallアイコンで一時停止中か調べます。

症状を切り分ける

Recallは対応PCでユーザーが保存に同意した後の画面を記録します。まず機種要件と保存状態を分けて確認します。保存が停止していた期間は後から自動補完されません。設定変更にWindows Helloの確認が必要な場合は本人の認証で進めます。

「Recallを開いても最近の画面履歴が増えない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 対応するCopilot+ PCではない
  • 保存がオフまたは一時停止中
  • 保存開始前の画面を履歴に探している

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. PCがRecallに対応するCopilot+ PCか確認します。
  2. 設定の『プライバシーとセキュリティ』『Recallとスナップショット』で保存がオンか確認します。
  3. タスクトレイのRecallアイコンで一時停止中か調べます。
  4. Windows Helloで設定変更を承認し、保存を許可した後の画面だけで新しい履歴を確認します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

スナップショットには画面上の個人情報や仕事の内容が含まれ得ます。保存をオンにする前にプライバシー設定と除外対象を確認してください。履歴を得るために会社の管理制限や本人認証を回避しないでください。
