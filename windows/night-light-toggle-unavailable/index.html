Windowsの夜間モードのスイッチがグレーで押せないとき

夜間モードをオンにする前に設定自体が選べない。表示環境とグラフィック機能を確認し、夜間モードの切り替えが利用可能かを見分けます。

公開・更新：2026年10月28日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

表示環境とグラフィック機能を確認し、夜間モードの切り替えが利用可能かを見分けます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 設定のシステムからディスプレイを開き、夜間モードのスイッチが選べるか確認します。
  2. 内蔵画面と外部画面で表示が異なるか、接続状態を変えずに見比べます。
  3. Windows UpdateとPCメーカーが案内する表示ドライバーの更新状況を確認します。

症状を切り分ける

スイッチが押せない場合は、オンでも色が変わらない場合と入口が異なります。Microsoftの表示と色の設定案内を基準に、まず利用できる画面と表示ドライバーを確認します。設定を有効にできてから色の強度や時刻指定を調べます。

「夜間モードをオンにする前に設定自体が選べない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 表示ドライバーまたは接続環境で機能が利用できない
  • 選択中の画面と設定対象が異なる
  • 組織管理の設定で変更できない

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 設定のシステムからディスプレイを開き、夜間モードのスイッチが選べるか確認します。
  2. 内蔵画面と外部画面で表示が異なるか、接続状態を変えずに見比べます。
  3. Windows UpdateとPCメーカーが案内する表示ドライバーの更新状況を確認します。
  4. 管理端末なら表示設定を制限する方針がないか管理者に確認します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

ドライバーを不明な配布サイトから入れたり、レジストリを一括変更したりしないでください。会社や学校のPCでは設定変更を試す前に管理者へ確認します。
