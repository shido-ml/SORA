Windows 11で撮ったスクリーンショットが見つからないとき

Windows 11で撮ったスクリーンショットが見つからないとき。安全な順番で原因を切り分ける手順と、データを守る注意点を案内します。

公開・更新：2026年10月21日読了目安：5分確認済み：Microsoft サポート：画面印刷のキーボードショートカット
結論

使ったショートカットで保存先が異なります。WindowsキーとPrint Screenキーで撮った画像は画像フォルダー内のスクリーンショットを確認し、WindowsキーとShiftキーとSキーの場合は切り取りツールとクリップボード側を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 使ったキーがWindowsキーとPrint Screenキーか、WindowsキーとShiftキーとSキーかを思い出す
  2. エクスプローラーの画像フォルダー内にあるスクリーンショットを確認する
  3. 切り取りツールを開き、撮影直後の通知や編集画面が残っていないか確認する

症状を切り分ける

ファイルを探す前に使った撮影方法を分けることが重要です。WindowsキーとPrint Screenキーの方法なら画像フォルダー内のスクリーンショットを探します。切り取りツールの方法なら、撮影しただけで目的の場所へファイル保存したと思い込まないよう、アプリ画面と通知を確かめます。

「Windows 11で撮ったスクリーンショットが見つからないとき」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 撮影方法ごとに画像ファイルとクリップボードの扱いが異なる
  • 保存場所として別の画像フォルダーを探している
  • 撮影後に保存操作を完了していない

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 使ったキーがWindowsキーとPrint Screenキーか、WindowsキーとShiftキーとSキーかを思い出す
  2. エクスプローラーの画像フォルダー内にあるスクリーンショットを確認する
  3. 切り取りツールを開き、撮影直後の通知や編集画面が残っていないか確認する
  4. 新たにテスト画像を撮り、直後にどこへ表示されるかを確認する

解決しない場合

テスト撮影でも画像が残らず、切り取りツールが起動しない場合は、表示されたエラーとWindowsの版を記録してサポートへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

探している画像が機密情報を含む場合、公開フォルダーやチャットに試し貼り付けしないでください。検索結果に出ないからといって一括削除や復元ツールをすぐ実行せず、まず撮影方法と保存先を確認します。
