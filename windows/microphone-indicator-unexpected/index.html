Windowsでマイク使用中の表示が突然出るとき

通話をしていないのにタスクバーでマイク利用を示す。プライバシー設定の最近の利用と実行中アプリを確認し、許可したアプリの動作か見分けます。

公開・更新：2026年10月28日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

プライバシー設定の最近の利用と実行中アプリを確認し、許可したアプリの動作か見分けます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 設定のプライバシーとセキュリティからマイクを開き、アクセスが許可されたアプリを確認します。
  2. 最近利用したアプリの表示と、現在開いている会議・録音・ブラウザーのタブを照合します。
  3. 不要なアプリだけマイクアクセスをオフにし、必要な通話や録音が使えるか確認します。

症状を切り分ける

マイクが使えない問題と、意図せず使われているように見える問題は対応が逆です。Microsoftのプライバシー画面にはアクセス許可と利用状況の確認手段があります。表示されたアプリと実際の作業を照合してから個別に権限を変えます。

「通話をしていないのにタスクバーでマイク利用を示す」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 会議や録音アプリが背景で動いている
  • ブラウザーのサイトにマイクを許可している
  • 不要なアプリがマイクアクセスを持っている

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 設定のプライバシーとセキュリティからマイクを開き、アクセスが許可されたアプリを確認します。
  2. 最近利用したアプリの表示と、現在開いている会議・録音・ブラウザーのタブを照合します。
  3. 不要なアプリだけマイクアクセスをオフにし、必要な通話や録音が使えるか確認します。
  4. 知らないアプリが繰り返し使うならアプリ名と時刻を記録し、Windowsセキュリティで確認します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

マイクアクセスを全アプリで一括停止すると必要な通話もできなくなります。不審なアプリを判断する前に表示時刻とアプリ名を記録し、組織端末なら管理者へ相談します。
