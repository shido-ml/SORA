Windows セキュリティが開かない・真っ白になる

Windows セキュリティが開かない・真っ白になるときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：Microsoft Support - Windows でアプリを修復する
結論

Windows更新、別のセキュリティ製品、組織の管理設定、アプリ破損を確認し、保護機能を無効化せずに復旧します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Windows Updateと再起動を行う
  2. 別のウイルス対策ソフトと職場・学校の管理表示を確認する
  3. 設定からWindows セキュリティアプリを修復する

症状を切り分ける

「Windows セキュリティ 開かない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 更新待ち・アプリ破損
  • 他社セキュリティ製品との役割切替
  • 組織ポリシーまたはシステムファイル不整合

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Windows Updateと再起動を行う
  2. 別のウイルス対策ソフトと職場・学校の管理表示を確認する
  3. 設定からWindows セキュリティアプリを修復する
  4. SFCとDISMでシステムファイルを検査する

解決しない場合

ウイルス感染が疑われる、または保護状態を確認できない場合はネットワークを切り、Microsoftサポートへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

更新画面が止まって見えても、まず通信・空き容量・再起動待ちを確認します。通常画面を操作できるなら再起動とWindows Updateのトラブルシューティングを行い、更新中の電源断は避けてください。
