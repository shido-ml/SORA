Windowsのクリップボードが別PCに同期しないとき

Win+Vの履歴は見えるのにコピーしたテキストが別のWindows PCへ届かない症状。両端末の同期設定とサインイン中のアカウントを確認します。

公開・更新：2026年11月3日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

両端末の同期設定とサインイン中のアカウントを確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 両方のPCでWin+Vを押しローカル履歴が有効か確かめる
  2. 設定の『システム』から『クリップボード』を開きデバイス間同期を確認する
  3. 両端末が同じMicrosoftアカウントまたは職場アカウントか照合する

症状を切り分ける

既存のWin+V履歴が表示されない問題と違い、この問題は片方の端末内ではコピー履歴を使えても別PCに届きません。Microsoftは同期が各端末の設定と同じアカウントに結び付くと説明します。まず単純な文字列で試し、ローカル履歴とクラウド同期を別の段階として確認してください。

「Win+Vの履歴は見えるのにコピーしたテキストが別のWindows PCへ届かない症状」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • デバイス間の同期がオフである
  • 別のMicrosoftアカウントでサインインしている
  • 職場のポリシーが同期を制限している

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 両方のPCでWin+Vを押しローカル履歴が有効か確かめる
  2. 設定の『システム』から『クリップボード』を開きデバイス間同期を確認する
  3. 両端末が同じMicrosoftアカウントまたは職場アカウントか照合する
  4. 小さなテキストで自動同期を試し、管理端末ならポリシーを管理者に確認する

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

パスワード、認証コード、機密情報を同期テストに使わないでください。クリップボードには意図せず個人情報が残る場合があります。共有PCや管理PCでは同期を有効にする前に利用規則を確認し、不要ならテスト後にオフへ戻してください。
