Windowsの回復ドライブでUSBを選べないとき

回復ドライブ作成画面に使いたいUSBメモリが出ない。USBの認識と回復ドライブ作成画面の対象条件を確認します。

公開・更新：2026年10月29日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

USBの認識と回復ドライブ作成画面の対象条件を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. USBメモリに必要なファイルがあれば別の場所へ退避します。
  2. エクスプローラーでUSBが認識され、容量が十分かを確認します。
  3. Windowsの『回復ドライブ』を開き、システムファイルのバックアップを含めるか選んで次へ進みます。

症状を切り分ける

回復ドライブはWindowsの修復や再インストールに備える起動用USBであり、個人ファイルを保存するファイル履歴とは用途が違います。エクスプローラーにUSBが見えないなら接続を、見えるのに候補にないなら容量と作成条件を確認します。

「回復ドライブ作成画面に使いたいUSBメモリが出ない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • USBがWindowsに認識されていない
  • 選んだ作成条件に容量が足りない
  • 回復ドライブ画面で別の記憶装置を見ている

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. USBメモリに必要なファイルがあれば別の場所へ退避します。
  2. エクスプローラーでUSBが認識され、容量が十分かを確認します。
  3. Windowsの『回復ドライブ』を開き、システムファイルのバックアップを含めるか選んで次へ進みます。
  4. 候補に出るUSBの容量と名前を照合し、別のドライブを誤って選ばないようにします。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

回復ドライブの作成では選択したUSB上の内容が消去されます。型番や容量だけで決めず、目的のUSBか必ず確認してください。個人ファイルのバックアップは別途必要で、回復ドライブだけでは写真や文書を復元できません。
