Wordの表の1行がページをまたいで分かれるとき

Wordの表を印刷すると、同じ行の内容が前ページと次ページに分断されて読みにくい。表の行のプロパティで「行の途中で改ページする」の設定を確認し、分割したくない行では解除します。

公開・更新：2026年11月8日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

表の行のプロパティで「行の途中で改ページする」の設定を確認し、分割したくない行では解除します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 分断されている行のセルを選択する
  2. 右クリックから「表のプロパティ」を開き「行」タブを選ぶ
  3. 「行の途中で改ページする」のチェックを外して確定する

症状を切り分ける

見出し行が消えるのか、同じデータ行の途中で切れるのかを印刷レイアウトで切り分けます。症状が起きるファイルや機器だけでなく、同じ機能を使う別の対象でも再現するか比べます。表示された文言と操作の直前に変えた設定を控え、一度に一つずつ確認して原因を絞ります。

「Wordの表を印刷すると、同じ行の内容が前ページと次ページに分断されて読みにくい」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 表の行内での改ページが許可されている
  • 行の内容が1ページの印刷可能な高さを超えている
  • 段落の改ページ設定が別途影響している

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 分断されている行のセルを選択する
  2. 右クリックから「表のプロパティ」を開き「行」タブを選ぶ
  3. 「行の途中で改ページする」のチェックを外して確定する
  4. 印刷レイアウトと印刷プレビューで、行全体が次ページへ移ったか確認する

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

長い行が用紙の高さに収まらない場合は設定だけで完全に1ページに収まらないため、余白や内容の整理を検討します。共有中のファイルや組織の設定では、編集前に所有者や管理者の方針を確認します。元のデータを残してから試し、結果が違えば変更を戻せるようにしてください。
