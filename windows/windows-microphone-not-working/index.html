Windows 11でマイクが反応しない・声を認識しない

Windows 11でマイクが反応しない・声を認識しないときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：Microsoft Support - Fix microphone problems
結論

物理ミュート、入力デバイス、Windowsのマイク許可、アプリ側の入力先を順に確認すると原因を切り分けられます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. ヘッドセットの接続と物理ミュートを確認する
  2. 設定のサウンドで正しい入力デバイスを選びテストする
  3. プライバシーとセキュリティでマイクアクセスを許可する

症状を切り分ける

「Windows 11 マイク 反応しない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 物理ミュートまたは誤った入力先
  • Windows・アプリのマイク権限
  • オーディオドライバーや端子の不調

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. ヘッドセットの接続と物理ミュートを確認する
  2. 設定のサウンドで正しい入力デバイスを選びテストする
  3. プライバシーとセキュリティでマイクアクセスを許可する
  4. アプリ側の入力先とドライバー更新を確認する

解決しない場合

別のマイクでも入力レベルが動かない場合は、PCメーカーまたは音響機器メーカーへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。
