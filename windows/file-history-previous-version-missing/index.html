Windowsのファイル履歴に以前の版が出ないときの確認手順

上書き前のファイルを戻したいが履歴がない。ファイル履歴が有効だった時期、バックアップ先、対象フォルダを確認します。Windowsバックアップで新PCへ復元する話とは別です。

公開・更新：2026年10月24日読了目安：5分確認済み：Microsoftサポート：ファイル履歴でバックアップ・復元する
結論

ファイル履歴が有効だった時期、バックアップ先、対象フォルダを確認します。Windowsバックアップで新PCへ復元する話とは別です。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 対象ファイルの元フォルダを開き、以前のバージョンとファイル履歴を確認します。
  2. ファイル履歴のバックアップ先ドライブが現在接続され、過去に有効だったか確認します。
  3. 対象フォルダがファイル履歴の保存範囲か、ファイル名や移動履歴を確認します。

症状を切り分ける

以前の版が表示されない場合、機能を今から有効にしても過去の内容は作られません。対象ファイルの保存場所と、上書き前に使っていたバックアップ先を確認します。現行ファイルは存在するのに古い版だけ必要な状態を、ファイルの完全な紛失と分けて調べます。バックアップ先の日時も照合します。

「上書き前のファイルを戻したいが履歴がない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • ファイル履歴が当時有効でなかった。
  • バックアップ先ドライブが接続されていない。
  • 対象ファイルが履歴対象外または別フォルダへ移動した。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 対象ファイルの元フォルダを開き、以前のバージョンとファイル履歴を確認します。
  2. ファイル履歴のバックアップ先ドライブが現在接続され、過去に有効だったか確認します。
  3. 対象フォルダがファイル履歴の保存範囲か、ファイル名や移動履歴を確認します。
  4. 候補があれば内容をプレビューし、現行版を別名保存してから復元先を決めます。

解決しない場合

履歴のバックアップ先が接続されているのに候補がない場合は元のパス、日時、バックアップ先をMicrosoftサポートへ伝えます。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

復元は現在のファイルを上書きする可能性があります。候補を確認する前に現行版を別名で保全してください。バックアップ先ドライブを初期化しないでください。履歴がない場合に復元できると断言せず別の保存先も探します。
