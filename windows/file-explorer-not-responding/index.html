Windowsでエクスプローラーが応答しない・固まる

ファイルやフォルダーを開くとエクスプローラーが固まるときに、特定場所、外付け機器、履歴、システム破損を切り分ける方法です。

公開・更新：2026年8月16日読了目安：4分確認済み：公式サポート情報
結論

特定フォルダーだけか、USB機器を外すと直るかを確認してからWindowsエクスプローラーを再起動します。クイックアクセス履歴の消去と更新を試し、同じ場所だけなら保存先の異常を疑います。

まず試すこと

  1. 外付けストレージとネットワークドライブを外し、タスクマネージャーからWindowsエクスプローラーを再起動する。
  2. エクスプローラーのオプションで履歴を消去し、「PC」を起点に開いて問題のフォルダーを一段ずつ特定します。
  3. 外部機器を外してExplorerを再起動します。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • どのフォルダーでも固まるか
  • USBやNASを外すと改善するか
  • 右クリック時だけ止まるか
  • ディスク使用率が100%になっていないか

考えられる原因

この症状で最初に疑うのは、クイックアクセス履歴、応答しない外付け・ネットワークドライブ、壊れたサムネイル、システムファイル不整合です。加えて、次の原因も順番に確認します。

  • 履歴やサムネイルキャッシュの不整合
  • 切断されたネットワーク場所
  • ストレージの読み取り遅延
  • シェル拡張またはシステムファイルの問題

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. 外付けストレージとネットワークドライブを外し、タスクマネージャーからWindowsエクスプローラーを再起動する。
  2. エクスプローラーのオプションで履歴を消去し、「PC」を起点に開いて問題のフォルダーを一段ずつ特定します。
  3. 外部機器を外してExplorerを再起動します。
  4. エクスプローラー履歴を消去します。
  5. Windows UpdateとDISM・SFCを実行します。
  6. 対象ドライブのエラーチェックと空き容量を確認します。

解決しない場合

特定ドライブから異音がする、SMART警告がある、重要ファイルを開くたび停止する場合は書き込みを増やさず、データ保護を優先して専門窓口へ相談します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
