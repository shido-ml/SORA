Windowsで空間オーディオを選べないとき

ヘッドホンでWindows Sonicなどの空間オーディオ設定が見つからない症状。再生中の出力機器を特定し、その機器のサウンド設定を開きます。

公開・更新：2026年11月3日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

再生中の出力機器を特定し、その機器のサウンド設定を開きます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 設定の『システム』から『サウンド』を開く
  2. 実際に音が出ているヘッドホンや再生デバイスを出力一覧で選ぶ
  3. その機器のプロパティで『空間オーディオ』とWindows Sonicの選択肢を確認する

症状を切り分ける

Windowsから音が一切出ない問題ではなく、通常の音は聞こえるのに空間オーディオの選択肢だけがない状態です。Microsoftの案内は再生デバイスのプロパティからWindows Sonic for Headphonesを選ぶ手順です。まず実際の出力先を特定し、機器を変えた場合に項目が現れるかを見ることでOS全体と機器固有の問題を分けます。

「ヘッドホンでWindows Sonicなどの空間オーディオ設定が見つからない症状」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 選択している出力機器が目的のヘッドホンと違う
  • 機器・ドライバーが空間オーディオを提供していない
  • アプリ側の音声設定とWindowsの出力先が一致していない

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 設定の『システム』から『サウンド』を開く
  2. 実際に音が出ているヘッドホンや再生デバイスを出力一覧で選ぶ
  3. その機器のプロパティで『空間オーディオ』とWindows Sonicの選択肢を確認する
  4. 別の出力機器と比較し、機器のドライバーとWindowsの更新状態を確認する

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

有料の音響アプリを購入する前に、無料のWindows Sonicと機器の対応状況を確認してください。ドライバーを非公式サイトから入れず、音量を上げすぎた状態でテストしないでください。難聴予防のため小さい音量から比べます。
