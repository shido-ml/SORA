Windows 11でHDRの切り替えが表示されないときの確認手順

HDR対応ディスプレイなのに設定が出ないとき、選択中の画面、複製設定、PCと接続の対応を確認する。

公開・更新：2026年10月22日読了目安：5分確認済み：Microsoft サポート：WindowsのHDR設定
結論

HDRを使いたいディスプレイを設定で選び、PCと画面の両方がHDRに対応しているか確認します。外部HDR画面をノートPCに複製していると非対応表示になる場合があるため、「拡張」に切り替えて確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 設定の「システム」→「ディスプレイ」でHDR対応の外部画面を選択する
  2. 選択した画面のHDR項目と「ディスプレイの機能」に表示される対応状態を読む
  3. ノートPCと外部画面を複製している場合は「これらのディスプレイを拡張」を選んで再確認する

症状を切り分ける

HDRのスイッチがないのか、スイッチはあるが映像が期待と違うのかを分けます。複数画面をつないでいる場合は対象の画面を選び直すだけで表示が変わることがあります。複製時に「サポートされていません」と出るなら、拡張表示で同じ画面を再確認してから機器の故障を疑います。

「Windows 11でHDRをオンにできない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • HDR非対応の画面を設定画面で選択している
  • 画面複製の構成がHDRに対応していない
  • PCの映像出力、ケーブル、ディスプレイのいずれかがHDR要件を満たさない

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 設定の「システム」→「ディスプレイ」でHDR対応の外部画面を選択する
  2. 選択した画面のHDR項目と「ディスプレイの機能」に表示される対応状態を読む
  3. ノートPCと外部画面を複製している場合は「これらのディスプレイを拡張」を選んで再確認する
  4. PC、ディスプレイ、ケーブルと接続端子のHDR対応条件をメーカーの仕様で確認する

解決しない場合

拡張表示でもHDR非対応と出る場合は、PC・画面・ケーブルの型番とWindowsの表示内容を控えてメーカーへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

HDR非対応のハードウェアをソフト設定だけで対応させることはできません。ケーブルや端子の仕様は機種で異なるため、購入や交換の前にメーカーの仕様を確認してください。画面設定を変える際は作業中のウィンドウの位置に注意します。
