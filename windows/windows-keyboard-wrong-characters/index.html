Windowsでキーボードを押すと違う文字が入力される

Windowsでキーボードを押すと違う文字が入力されるときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：Microsoft Support - Keyboard
結論

日本語・英語配列、入力言語、NumLock、IMEを確認し、ソフト設定か物理キー故障かを切り分けます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 画面の入力言語とIME状態を確認する
  2. 日本語106/109キーと英語101/102キーの配列設定を確認する
  3. NumLock・Fn Lock・固定キーを確認する

症状を切り分ける

「Windows キーボード 違う文字 入力」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • キーボード配列の誤設定
  • 入力言語・IME・ロックキー
  • 物理キー故障や液体侵入

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 画面の入力言語とIME状態を確認する
  2. 日本語106/109キーと英語101/102キーの配列設定を確認する
  3. NumLock・Fn Lock・固定キーを確認する
  4. スクリーンキーボードと別キーボードで再現を比較する

解決しない場合

別OSやBIOS画面でも誤入力する場合はハード故障の可能性が高いためメーカーへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。
