スマートフォン連携でAndroidの通知だけ表示されないとき

スマートフォン連携は接続できるのにスマホの通知がPCに出ない。接続設定ではなく通知アクセスと省電力設定を調べます。機密通知はOS側の制限も確認します。

公開・更新：2026年10月31日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

接続設定ではなく通知アクセスと省電力設定を調べます。機密通知はOS側の制限も確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Windowsのスマートフォン連携で対象Android端末が接続済みか確認します。
  2. Androidの設定でスマートフォン連携アプリへの通知アクセスが許可されているか調べます。
  3. Android側のバッテリー最適化やバックグラウンド制限を確認します。

症状を切り分ける

スマートフォン連携のペアリングが成功していても、通知表示にはAndroid側の通知アクセスが別途必要です。Microsoftの説明はバッテリー最適化やPCの通知抑制も挙げています。さらにAndroid 15以降で機密情報と判定された通知は転送されないため、一般通知と認証コードなどを同じ不具合として扱わず比較します。

「スマートフォン連携は接続できるのにスマホの通知がPCに出ない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • Android側で通知アクセスを許可していない
  • 省電力設定がバックグラウンド動作を止めている
  • Android 15以降の機密通知が転送対象外

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Windowsのスマートフォン連携で対象Android端末が接続済みか確認します。
  2. Androidの設定でスマートフォン連携アプリへの通知アクセスが許可されているか調べます。
  3. Android側のバッテリー最適化やバックグラウンド制限を確認します。
  4. PC側の通知設定と集中モードを確認し、通常通知と機密扱いの通知を分けて試します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

通知アクセスを許可するとPCに私的な通知が表示される可能性があります。共有PCでは許可範囲と画面ロックを先に確認してください。機密通知の制限を回避するために端末の安全設定を弱めないでください。
