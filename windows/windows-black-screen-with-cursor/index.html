Windowsにサインイン後、画面が真っ黒でカーソルだけ表示される

Windowsへサインインした後に黒画面とマウスポインターだけになるときに、表示出力、Explorer、ドライバーを切り分ける手順です。

公開・更新：2026年8月16日読了目安：4分確認済み：公式サポート情報
結論

Windows＋Ctrl＋Shift＋Bでグラフィックドライバーをリセットし、Ctrl＋Alt＋Deleteが開くか確認します。タスクマネージャーを起動できるならexplorer.exeを新しいタスクとして実行します。

先に確認してください黒画面中に何度も電源を切ると更新やディスク処理を損なうことがあります。アクセスランプが動いている間は少し待ってください。

まず試すこと

  1. 外部ディスプレイを外し、Windows＋Ctrl＋Shift＋Bを押して画面が再描画されるか確認する。
  2. Ctrl＋Shift＋Escから「新しいタスクの実行」を選び、explorer.exeを入力してデスクトップが戻るか試します。
  3. 外部画面を外し表示ドライバーをリセットします。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • メーカーのロゴやサインイン画面までは映るか
  • Ctrl＋Alt＋Deleteが反応するか
  • 外部画面へ表示されていないか
  • 更新やドライバー変更の直後か

考えられる原因

この症状で最初に疑うのは、誤った表示先、Explorer未起動、グラフィックドライバー、更新や常駐ソフトの不整合です。加えて、次の原因も順番に確認します。

  • 投影先や解像度のずれ
  • Windowsエクスプローラーの起動失敗
  • GPUドライバーの停止
  • 更新・スタートアップアプリの競合

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. 外部ディスプレイを外し、Windows＋Ctrl＋Shift＋Bを押して画面が再描画されるか確認する。
  2. Ctrl＋Shift＋Escから「新しいタスクの実行」を選び、explorer.exeを入力してデスクトップが戻るか試します。
  3. 外部画面を外し表示ドライバーをリセットします。
  4. タスクマネージャーからexplorer.exeを起動します。
  5. セーフモードで直近の表示ドライバーを戻します。
  6. 更新履歴と復元ポイントを確認します。

解決しない場合

BIOSロゴから映らない、画面に線や割れがある、セーフモードでも黒画面の場合はPCメーカーへ診断を依頼します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
