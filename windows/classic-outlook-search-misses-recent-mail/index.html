従来版Outlookの検索で最近のメールだけ出ないとき

受信箱で開ける新しいメールが検索結果に現れない症状。検索範囲とWindowsの検索インデックス状態を確認します。

公開・更新：2026年11月2日読了目安：5分確認済み：製品提供元の公式ヘルプ
結論

検索範囲とWindowsの検索インデックス状態を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 対象メールを受信箱で直接開けるか確認し、実際に保存されていることを確かめます。
  2. 従来版Outlookの検索範囲が現在のフォルダー・現在のメールボックス・すべてのメールボックスのどれか確認します。
  3. Windowsの『インデックスのオプション』でMicrosoft Outlookが対象になっているか調べます。

症状を切り分ける

オフライン時にメール本文を開けない問題ではなく、手動では見えるメールが従来版Outlookの検索だけに出ない問題です。Microsoftは検索範囲とWindowsのインデックスを別々に確認するよう案内しています。最初からインデックスを作り直すと時間がかかるため、対象メールの存在と範囲を先に確認します。

「受信箱で開ける新しいメールが検索結果に現れない症状」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 検索範囲が別フォルダーや一つのメールボックスに限定されている。
  • Windows検索のインデックスにOutlookが含まれていない。
  • インデックス作成が途中で最近のメールをまだ取り込んでいない。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 対象メールを受信箱で直接開けるか確認し、実際に保存されていることを確かめます。
  2. 従来版Outlookの検索範囲が現在のフォルダー・現在のメールボックス・すべてのメールボックスのどれか確認します。
  3. Windowsの『インデックスのオプション』でMicrosoft Outlookが対象になっているか調べます。
  4. インデックスの構築が完了していない場合は待ち、必要な場合だけ公式の再構築手順を検討します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

検索結果にないことを削除済みと決めつけてメールを移動・消去しないでください。インデックス再構築は結果が揃うまで時間がかかります。職場アカウントの検索設定やポリシーを自己判断で変更せず、管理者に状態を伝えてください。
