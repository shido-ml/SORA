Microsoft Storeのダウンロードが進まない

Microsoft Storeのアプリが保留中・取得中のまま進まないときに、通信、時刻、アカウント、キャッシュ、更新を確認する手順です。

公開・更新：2026年8月16日読了目安：4分確認済み：公式サポート情報
結論

ほかのダウンロードを一時停止し、PCの日時と地域、Microsoftアカウント、Windows Updateを確認します。次にwsreset.exeでStoreキャッシュをリセットしてください。

まず試すこと

  1. Microsoft Storeのライブラリを開き、同時に待機中の更新を止めて対象アプリ1件だけ再試行する。
  2. Win＋Rでwsreset.exeを実行し、Storeが再度開いたらサインイン状態を確認してダウンロードし直します。
  3. 待機中の項目を止めて1件だけ試します。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • エラーコードが表示されるか
  • Web閲覧やWindows Updateは動くか
  • Cドライブに十分な空きがあるか
  • 会社・学校の端末で制限されていないか

考えられる原因

この症状で最初に疑うのは、Storeキューの停止、日時や地域の不一致、キャッシュ破損、Microsoftアカウント、Windows Update未完了です。加えて、次の原因も順番に確認します。

  • ダウンロードキューの競合
  • Storeキャッシュの不整合
  • 時刻・地域・アカウント認証
  • 更新サービスや組織ポリシー

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. Microsoft Storeのライブラリを開き、同時に待機中の更新を止めて対象アプリ1件だけ再試行する。
  2. Win＋Rでwsreset.exeを実行し、Storeが再度開いたらサインイン状態を確認してダウンロードし直します。
  3. 待機中の項目を止めて1件だけ試します。
  4. 日時と地域を自動設定にします。
  5. wsreset.exeを実行します。
  6. 設定からMicrosoft Storeの修復を行います。

解決しない場合

複数アプリで同じエラーコードが続き、修復や更新でも改善しない場合は、コードとWindowsバージョンを添えてMicrosoftサポートへ相談します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
