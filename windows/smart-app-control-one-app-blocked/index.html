Smart App Controlが特定アプリをブロックしたとき

Windowsで一つのアプリが信頼されていないと表示され起動しない。個別の許可例外がない仕様を踏まえて提供元を確認します。 ブロック画面のアプリ名、入手元、表示された理由を記録します。

公開・更新：2026年11月1日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

個別の許可例外がない仕様を踏まえて提供元を確認します。 ブロック画面のアプリ名、入手元、表示された理由を記録します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. ブロック画面のアプリ名、入手元、表示された理由を記録します。
  2. アプリが正規の配布元から入手した最新版か確認します。
  3. MicrosoftのSmart App Controlの案内で、個別アプリだけを通す例外がないことを確認します。

症状を切り分ける

MicrosoftのFAQによるとSmart App Controlはアプリの安全性や署名を評価し、不明なアプリをブロックすることがあります。個別のアプリだけを例外として通す機能はありません。保護自体をオンにできない既存記事とは違い、本記事は保護が動作した結果、特定アプリが止まった状況です。まず入手元と署名を確認します。

「Windowsで一つのアプリが信頼されていないと表示され起動しない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • アプリの署名がないか無効
  • 保護サービスが安全性を十分に判定できない
  • 個別許可のボタンがあると思っている

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. ブロック画面のアプリ名、入手元、表示された理由を記録します。
  2. アプリが正規の配布元から入手した最新版か確認します。
  3. MicrosoftのSmart App Controlの案内で、個別アプリだけを通す例外がないことを確認します。
  4. 正規アプリが誤って止まる場合は提供元へ署名などの対応を相談し、必要な作業は信頼できる別手段を検討します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

アプリを動かすためだけにSmart App Control全体を無効にすることは勧めません。保護の解除は端末全体の安全性に影響します。仕事で必要なアプリなら組織のIT担当者と提供元へ確認し、知らない配布サイトから別版を入れないでください。
