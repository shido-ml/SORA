Windowsセキュリティで許可した脅威を取り消すとき

誤って脅威を許可した後に保護対象へ戻したい。許可済み脅威の一覧から対象を特定して許可を取り消します。

公開・更新：2026年10月31日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

許可済み脅威の一覧から対象を特定して許可を取り消します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Windowsセキュリティの「ウイルスと脅威の防止」を開きます。
  2. 「許可された脅威」を開き、名前と対象を確認します。
  3. 誤って許可した項目を選び、「許可しない」を選択します。

症状を切り分ける

Windowsセキュリティの公式手順では「許可された脅威」に移した項目は「許可しない」で戻せます。履歴に表示されたすべての検出を同じものとみなさず、許可した名前と時刻を照合します。再び検出される場合は、元ファイルの所在と検出名を記録し、必要なら管理者やMicrosoftの案内に沿って調べます。

「誤って脅威を許可した後に保護対象へ戻したい」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 脅威を許可したまま一覧に残っている
  • 保護の履歴と許可された脅威を混同している
  • 別の脅威まで一括して設定変更しようとしている

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Windowsセキュリティの「ウイルスと脅威の防止」を開きます。
  2. 「許可された脅威」を開き、名前と対象を確認します。
  3. 誤って許可した項目を選び、「許可しない」を選択します。
  4. 保護の履歴と最新のスキャン結果を確認し、再検出がある場合は表示内容を記録します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

疑わしいファイルを動かして再実行したり、リアルタイム保護全体を切ったりしないでください。業務端末では組織の除外設定や管理ポリシーが関係するため、自己判断で例外を追加せず管理者に相談してください。
