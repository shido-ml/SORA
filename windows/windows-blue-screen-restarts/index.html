Windows 11でブルースクリーンが出て再起動する

Windows 11で青い画面や黒い画面と停止コードが表示され、PCが再起動するときに、コードを記録してドライバー・更新・機器を安全に切り分ける方法を解説します。

公開・更新：2026年8月15日読了目安：4分確認済み：公式サポート情報
結論

最初に停止コードと、表示されていれば原因ファイル名を写真に残します。直前に追加した機器を外し、Windows Updateとデバイスマネージャーを確認してください。同じ停止コードが繰り返す場合は、セーフモードや回復オプションへ進みます。

先に確認してください再起動を繰り返すPCで保存作業を続けるとデータが破損することがあります。起動できるうちに重要ファイルを退避し、分解や部品の抜き差しはメーカー保証を確認してから行ってください。

まず試すこと

  1. ブルースクリーンに表示された停止コード（例：MEMORY_MANAGEMENT）とファイル名をスマートフォンで撮影する。
  2. 直前に増設・接続したUSB機器やメモリなどを外して起動し、設定の「Windows Update」で更新を適用します。
  3. 起動できる場合は重要データをバックアップします。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • 毎回同じ停止コードか、コードが変わるか
  • 特定の機器・アプリ・ゲームを使った直後だけ発生するか
  • デバイスマネージャーに黄色い警告マークがないか
  • システムドライブに10〜15%程度の空きがあるか

考えられる原因

この症状で最初に疑うのは、新しく追加した機器やドライバー、Windows更新、空き容量不足、メモリやストレージの不調です。加えて、次の原因も順番に確認します。

  • 最近更新・追加されたデバイスドライバー
  • Windows Updateまたはアプリとの互換性
  • メモリ、SSD、増設機器などハードウェアの不調
  • システムファイルの破損や極端な空き容量不足

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. ブルースクリーンに表示された停止コード（例：MEMORY_MANAGEMENT）とファイル名をスマートフォンで撮影する。
  2. 直前に増設・接続したUSB機器やメモリなどを外して起動し、設定の「Windows Update」で更新を適用します。
  3. 起動できる場合は重要データをバックアップします。
  4. セーフモードで起動し、直前に追加したドライバーやアプリを戻す・削除する前後で再現を比較します。
  5. Windows セキュリティでマルウェアスキャンを行い、PCメーカーの診断機能も実行します。
  6. 改善しなければ、復元ポイントやスタートアップ修復などWindowsの回復オプションを検討します。

解決しない場合

起動直後から再起動を繰り返す、同じ停止コードが頻発する、異音や異常発熱がある場合は使用を止め、停止コードと発生時刻を添えてPCメーカーへ診断を依頼します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
