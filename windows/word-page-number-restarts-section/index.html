Wordの途中でページ番号が1に戻るとき

Wordの文書で章が変わるところからページ番号が突然1に戻り、通し番号にならない。セクション区切りと各セクションのページ番号形式を確認し、必要なら前のセクションから続けます。

公開・更新：2026年11月7日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

セクション区切りと各セクションのページ番号形式を確認し、必要なら前のセクションから続けます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 「ホーム」の編集記号表示でページ番号が変わる前後にセクション区切りがあるか確認する
  2. 番号が戻った章のヘッダーまたはフッターを開く
  3. 「前と同じヘッダー/フッター」のリンクとページ番号の書式設定を確認する

症状を切り分ける

番号が戻る位置を確認し、ページ区切りかセクション区切りかを見分けます。変更前の文書をコピーして、意図した章立てが保たれるか比べます。 同じアカウントと端末で変更前後を比較し、再現する条件を記録します。設定を一度に複数変えず、結果を見て次の確認に進みます。

「Wordの文書で章が変わるところからページ番号が突然1に戻り、通し番号にならない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 章のセクションに開始番号1が設定されている
  • セクション間でヘッダーやフッターのリンクが外れている
  • 改ページとセクション区切りを混同している

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 「ホーム」の編集記号表示でページ番号が変わる前後にセクション区切りがあるか確認する
  2. 番号が戻った章のヘッダーまたはフッターを開く
  3. 「前と同じヘッダー/フッター」のリンクとページ番号の書式設定を確認する
  4. 通し番号が必要ならページ番号の開始値を変更して各章の表示を確認する

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

長い文書のセクション区切りを削除すると章ごとの余白や向きも変わる場合があります。番号の設定だけを先に確認し、元ファイルを保全してください。 操作前に対象と影響を確認し、仕事や共有のアカウントでは管理者の方針を優先してください。
