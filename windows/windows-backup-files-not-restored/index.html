Windowsバックアップ後に新しいPCへファイルが戻らないときの確認手順

Windowsバックアップ後に新しいPCへファイルが戻らないときの確認手順。Windowsバックアップの復元対象とOneDriveに保存されるファイルを分けて確認します。同じMicrosoftアカウントでサインインし、旧PCで選択したフォルダとOneDriveの同期状態を調べます。

公開・更新：2026年10月23日読了目安：6分確認済み：Microsoftサポート：Windowsバックアップを使用したバックアップと復元
結論

Windowsバックアップの復元対象とOneDriveに保存されるファイルを分けて確認します。同じMicrosoftアカウントでサインインし、旧PCで選択したフォルダとOneDriveの同期状態を調べます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 旧PCのWindowsバックアップでアプリ・設定・フォルダのどれを有効にしたか、利用したMicrosoftアカウントを確認する。
  2. 新PCで同じMicrosoftアカウントのOneDriveにサインインし、Web版OneDriveに文書があるかを確認する。
  3. Webにあるファイルは新PCの同期とエクスプローラーで探し、Webにもない場合は旧PC側の元ファイルを保持したまま保存先を確認する。

症状を切り分ける

新PCでアプリのピンだけ戻る場合は、ファイルがOneDriveに保存されているか先に調べます。Web版OneDriveにあるなら同期表示の問題、Webにもなく旧PCにはあるなら旧PCからのバックアップ設定を確認します。新旧PCを同時に見られる間に比較してください。

「新PCでアプリや設定はあるのに文書が見つからない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 旧PCでファイルのバックアップ対象フォルダを選んでいなかった。
  • 新PCで別のMicrosoftアカウントにサインインしている。
  • Windowsバックアップのアプリピンや設定の復元を、すべてのローカルファイルの複製と取り違えている。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 旧PCのWindowsバックアップでアプリ・設定・フォルダのどれを有効にしたか、利用したMicrosoftアカウントを確認する。
  2. 新PCで同じMicrosoftアカウントのOneDriveにサインインし、Web版OneDriveに文書があるかを確認する。
  3. Webにあるファイルは新PCの同期とエクスプローラーで探し、Webにもない場合は旧PC側の元ファイルを保持したまま保存先を確認する。
  4. 復元したアプリのピンと実際に再インストールされたアプリを分け、Microsoft Store対象外は別途インストーラーが必要か確認する。

解決しない場合

旧PCにデータがあるのにバックアップ経路で見つからなければ、対象フォルダとアカウント、Web版の状態を記録してMicrosoftサポートへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

旧PCの初期化や売却を急がないでください。Webと新PCで必要なファイルを実際に開いて確認するまで元データを残します。OneDriveで削除した項目は同期先にも反映され得るため、整理やアカウント解除は最後にしてください。
