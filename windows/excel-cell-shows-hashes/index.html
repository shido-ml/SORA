Excelのセルに「#####」だけ表示されるとき

Excelで数値や日付が見えるはずのセルに「#####」が並び、値を読めない。まず列幅を広げます。日付や時刻の計算結果が負数の場合は、幅を広げても同じ表示になることがあります。

公開・更新：2026年11月7日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

まず列幅を広げます。日付や時刻の計算結果が負数の場合は、幅を広げても同じ表示になることがあります。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 対象セルを選び数式バーに元の値や式が残るか確認する
  2. 列見出し右端をドラッグまたはダブルクリックして列幅を広げる
  3. 表示が変わらない場合はセルの表示形式が日付・時刻か確認する

症状を切り分ける

数式バーに値が残っていれば消失ではなく表示の問題です。列幅で直る場合と、負の日付計算を直す必要がある場合を分けます。 同じアカウントと端末で変更前後を比較し、再現する条件を記録します。設定を一度に複数変えず、結果を見て次の確認に進みます。

「Excelで数値や日付が見えるはずのセルに「#####」が並び、値を読めない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 列幅が値の表示に足りない
  • 負の日付・時刻を表示しようとしている
  • 数式の結果と表示形式が合っていない

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 対象セルを選び数式バーに元の値や式が残るか確認する
  2. 列見出し右端をドラッグまたはダブルクリックして列幅を広げる
  3. 表示が変わらない場合はセルの表示形式が日付・時刻か確認する
  4. 日付計算が負数になっていないか参照元と式を確認する

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

値を消して入れ直す前に元の数式と参照先を確認してください。共有表では列幅変更が印刷レイアウトにも影響する場合があります。 操作前に対象と影響を確認し、仕事や共有のアカウントでは管理者の方針を優先してください。
