Windowsでサンドボックスの機能が表示されないとき

Windowsの機能一覧やスタートにWindows Sandboxが見つからない。Windowsのエディションと仮想化の前提条件を確認します。

公開・更新：2026年10月26日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

Windowsのエディションと仮想化の前提条件を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 設定のシステム情報でWindows 11のエディションを確認します。
  2. Homeの場合はSandboxの対象外かをMicrosoftの対応表で確認し、機能追加を無理に試しません。
  3. Pro・Enterprise・Educationなら仮想化対応と有効状態、メモリなどの前提を確認します。

症状を切り分ける

アプリの検索結果に出ない理由を、インストール不良だけと決めつけないことが大切です。MicrosoftはSandboxがPro、Enterprise、Educationなどで提供され、Homeでは非対応と説明しています。エディションが対応していても仮想化やメモリの条件が必要です。

「Windowsの機能一覧やスタートにWindows Sandboxが見つからない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • Homeなど対象外エディションを利用している。
  • 仮想化が使えないか有効でない。
  • 必要なハードウェア条件を満たさない。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 設定のシステム情報でWindows 11のエディションを確認します。
  2. Homeの場合はSandboxの対象外かをMicrosoftの対応表で確認し、機能追加を無理に試しません。
  3. Pro・Enterprise・Educationなら仮想化対応と有効状態、メモリなどの前提を確認します。
  4. 対応端末であればWindowsの機能からSandboxを有効にする公式手順へ進みます。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

非対応エディションで非公式なスクリプトやライセンス回避の手順を実行しないでください。BIOSの仮想化設定を変更する場合は機種の公式案内に従い、業務用端末では管理者に相談します。
