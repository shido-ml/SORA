WordでURLを入力すると勝手にリンクになるとき

Wordの文書にWebアドレスを入力して改行すると自動で青いリンクに変わる。自動ハイパーリンクの設定を確認します。既存リンクだけ外す操作と、今後の自動変換を止める設定は別です。

公開・更新：2026年11月8日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

自動ハイパーリンクの設定を確認します。既存リンクだけ外す操作と、今後の自動変換を止める設定は別です。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 既にできたリンクは右クリックして「ハイパーリンクの削除」を選ぶ
  2. 今後も自動変換を止めるなら「ファイル」→「オプション」→「文章校正」を開く
  3. 「オートコレクトのオプション」の入力時に自動で書式設定する項目を開く

症状を切り分ける

一つの既存リンクだけ消したいのか、これから入力するURLの自動変換を止めたいのかを分けます。症状が起きるファイルや機器だけでなく、同じ機能を使う別の対象でも再現するか比べます。表示された文言と操作の直前に変えた設定を控え、一度に一つずつ確認して原因を絞ります。

「Wordの文書にWebアドレスを入力して改行すると自動で青いリンクに変わる」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザーアカウントでも同じ症状が起きるか
  • Windows Updateや設定変更の直後から始まったか
  • 接続機器や常駐アプリを外すと変化するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 自動書式設定のURL変換が有効
  • 既存リンクの削除と今後の自動変換停止を混同した
  • Ctrlを押して開く動作の設定をリンク生成設定と取り違えた

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 既にできたリンクは右クリックして「ハイパーリンクの削除」を選ぶ
  2. 今後も自動変換を止めるなら「ファイル」→「オプション」→「文章校正」を開く
  3. 「オートコレクトのオプション」の入力時に自動で書式設定する項目を開く
  4. 「インターネットとネットワークのアドレスをハイパーリンクに変更する」を外し、新しいURLで動作を試す

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います回復、リセット、ドライバー削除を行う前に、BitLocker回復キーと必要なファイルのバックアップを確認してください。

文書全体のリンク一括削除では必要な参照先も失われます。共有文書ではURLのクリック可否を確認してください。共有中のファイルや組織の設定では、編集前に所有者や管理者の方針を確認します。元のデータを残してから試し、結果が違えば変更を戻せるようにしてください。
