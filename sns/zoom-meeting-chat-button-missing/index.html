Zoomミーティングでチャットボタンが見えないとき

会議中に参加者へチャットを送る操作が出ない。アカウントの会議チャット設定と、開催者の会議内制限を確認します。

公開・更新：2026年10月29日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

アカウントの会議チャット設定と、開催者の会議内制限を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 会議画面のツールバーや『詳細』メニューにチャットがないか確認します。
  2. 開催者へ、その会議で参加者のチャットを許可しているか確認します。
  3. 自分が管理者ならZoom Webポータルのミーティング内チャット設定を確認します。

症状を切り分ける

ファイル転送のボタンがない症状と、チャット欄そのものがない症状は別です。会議中のツールバーを確認し、開催者にその会議だけの制限を尋ねます。どの会議でもないならアカウントや組織の設定を確認します。参加者と開催者で見え方を比べます。

「会議中に参加者へチャットを送る操作が出ない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • ブラウザ版、アプリ版、別端末で結果が変わるか
  • 特定の相手や機能だけか、サービス全体で起きるか
  • 通信、権限、アカウント制限、サービス障害のどれに当てはまるか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 会議チャットがアカウント単位で無効
  • 開催者がその会議のチャットを制限
  • 画面幅のためボタンが詳細メニュー内にある

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 会議画面のツールバーや『詳細』メニューにチャットがないか確認します。
  2. 開催者へ、その会議で参加者のチャットを許可しているか確認します。
  3. 自分が管理者ならZoom Webポータルのミーティング内チャット設定を確認します。
  4. 組織で項目がロックされている場合は管理者に可否を確認します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますログアウト、再インストール、アカウント削除の前に、引き継ぎ情報、下書き、トーク履歴、二段階認証を確認してください。

開催者や組織がチャットを制限している場合は、参加者側で勝手に解除できません。重要な連絡は開催者が指定した別の経路を使い、設定を変える前に会議の記録や参加者のプライバシーを考慮します。
