LINEのトーク履歴が消えた・表示されない

LINEの機種変更・再インストール後や一部トークで履歴が消えたときに、バックアップ、アカウント、非表示・削除を確認する方法です。

公開・更新：2026年8月16日読了目安：4分確認済み：公式サポート情報
結論

アカウント自体が同じか、トークルームを非表示にしていないかを確認します。機種変更や再インストール後の履歴は、事前に作成した標準・プレミアムバックアップから復元できる範囲に限られます。

先に確認してください現状の端末で新しいバックアップを実行すると、古いバックアップを上書きする場合があります。復元可否を確認する前に再インストールしないでください。

まず試すこと

  1. 友だち・グループが同じアカウントに残るか確認し、設定のトークバックアップに表示される最終日時を確認する。
  2. バックアップがある場合は、OSとLINEの種類に合う公式手順を確認し、同じApple IDまたはGoogleアカウントで復元します。
  3. 現状を変えずバックアップ情報を確認します。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • 友だち一覧や購入履歴は同じか
  • トークルームを非表示にしていないか
  • バックアップ日時と保存先アカウント
  • 機種変更・再インストール・端末故障のどれか

考えられる原因

この症状で最初に疑うのは、トークルーム削除・非表示、別LINEアカウント、バックアップ未作成、引き継ぎ時の復元スキップ、Letter Sealingの影響です。加えて、次の原因も順番に確認します。

  • トークルームの削除・非表示
  • 別アカウントへのログイン
  • バックアップ未作成または上書き
  • 引き継ぎ方法・暗号化条件の違い

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. 友だち・グループが同じアカウントに残るか確認し、設定のトークバックアップに表示される最終日時を確認する。
  2. バックアップがある場合は、OSとLINEの種類に合う公式手順を確認し、同じApple IDまたはGoogleアカウントで復元します。
  3. 現状を変えずバックアップ情報を確認します。
  4. 非表示リストと相手検索を確認します。
  5. 公式手順で対応バックアップだけ復元します。
  6. 復元不能な履歴は相手にテキスト共有を依頼します。

解決しない場合

アカウントや購入履歴まで違う場合は別アカウントの可能性があります。新規登録を進めずLINEサポートへ登録情報を添えて相談します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
