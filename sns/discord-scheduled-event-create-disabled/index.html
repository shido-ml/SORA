Discordでサーバーの予定イベントを作成できないとき

予定イベントの作成が一つのサーバーやチャンネルで許可されない症状。サーバーとチャンネル双方のイベント権限を確認します。 対象サーバーの予定イベント画面で作成操作が表示されるか確認します。

公開・更新：2026年11月2日読了目安：5分確認済み：製品提供元の公式ヘルプ
結論

サーバーとチャンネル双方のイベント権限を確認します。 対象サーバーの予定イベント画面で作成操作が表示されるか確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 対象サーバーの予定イベント画面で作成操作が表示されるか確認します。
  2. 自分のロールに『イベントを作成』の権限があるかサーバー管理者へ確認します。
  3. イベントを行う特定チャンネルの権限で作成・管理が制限されていないか管理者に調べてもらいます。

症状を切り分ける

招待リンクが無効な問題やチャンネルにメッセージを投稿できない問題とは別です。Discord公式はイベントの作成・管理権限がサーバー単位だけでなく、チャンネルとカテゴリでも設定できると説明します。どのサーバー・チャンネルで再現するかを分け、利用者側で権限を回避しないでください。

「予定イベントの作成が一つのサーバーやチャンネルで許可されない症状」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • ブラウザ版、アプリ版、別端末で結果が変わるか
  • 特定の相手や機能だけか、サービス全体で起きるか
  • 通信、権限、アカウント制限、サービス障害のどれに当てはまるか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • サーバーのロールにイベント作成権限がない。
  • 特定チャンネルまたはカテゴリで作成権限が制限されている。
  • 作成と管理の権限を混同し、編集できないイベントを作成不可と判断した。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 対象サーバーの予定イベント画面で作成操作が表示されるか確認します。
  2. 自分のロールに『イベントを作成』の権限があるかサーバー管理者へ確認します。
  3. イベントを行う特定チャンネルの権限で作成・管理が制限されていないか管理者に調べてもらいます。
  4. 許可される場所でだけ短い試験イベントを作り、日時とチャンネルを確認してから公開します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますログアウト、再インストール、アカウント削除の前に、引き継ぎ情報、下書き、トーク履歴、二段階認証を確認してください。

権限がないまま別アカウントを使ってイベントを作らないでください。イベントには参加者や開催場所が表示されるため、公開範囲を管理者と確認します。ロールの変更は他の機能にも影響するので、必要な範囲を管理者が判断してください。
