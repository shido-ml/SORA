LINEの認証番号がSMSで届かない

LINEの認証番号がSMSで届かないときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：LINE Help Center
結論

国番号と電話番号、SMS・迷惑電話拒否、電波、再送制限を確認し、表示される場合は音声通話認証を使います。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 国・電話番号とSIMの受信状態を確認する
  2. SMS拒否・海外番号拒否を確認する
  3. 時間を空けて再送または音声認証を試す

症状を切り分ける

「LINE 認証番号 届かない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • ブラウザ版、アプリ版、別端末で結果が変わるか
  • 特定の相手や機能だけか、サービス全体で起きるか
  • 通信、権限、アカウント制限、サービス障害のどれに当てはまるか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 番号・回線状態
  • SMS拒否設定
  • 短時間の再送制限

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 国・電話番号とSIMの受信状態を確認する
  2. SMS拒否・海外番号拒否を確認する
  3. 時間を空けて再送または音声認証を試す
  4. 短時間の連続再送を止めて一定時間待ち、画面に表示される場合だけ音声通話認証を選んで番号を第三者へ伝えない

解決しない場合

認証番号は誰にも伝えず、届かない場合は通信事業者とLINE公式へ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますログアウト、再インストール、アカウント削除の前に、引き継ぎ情報、下書き、トーク履歴、二段階認証を確認してください。
