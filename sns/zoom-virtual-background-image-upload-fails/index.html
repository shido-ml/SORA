Zoomで仮想背景の画像を追加できないとき

Zoomの仮想背景メニューは使えるが、自分の画像を追加すると失敗する。画像の形式と容量、アカウントでの背景追加許可を確認します。

公開・更新：2026年11月6日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

画像の形式と容量、アカウントでの背景追加許可を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Zoomの仮想背景で標準画像を選べるか確認し、機能全体の問題と区別する
  2. 追加する画像が24ビットのPNGまたはJPEGか、15MB以下か確かめる
  3. 対応する画像を小さな別名ファイルとして用意し、再度追加する

症状を切り分ける

標準背景が使えるならカメラ要件より先に画像ファイルを調べます。追加ボタン自体がない場合は組織の提供設定を確認してください。 変更前後の表示を同じ端末・同じアカウントで比較し、どの条件でだけ再現するか記録します。これにより設定の問題と別の症状を取り違えずに済みます。

「Zoomの仮想背景メニューは使えるが、自分の画像を追加すると失敗する」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • ブラウザ版、アプリ版、別端末で結果が変わるか
  • 特定の相手や機能だけか、サービス全体で起きるか
  • 通信、権限、アカウント制限、サービス障害のどれに当てはまるか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 画像形式または容量が要件外
  • 画像ファイル自体が破損
  • 組織の背景追加制限

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Zoomの仮想背景で標準画像を選べるか確認し、機能全体の問題と区別する
  2. 追加する画像が24ビットのPNGまたはJPEGか、15MB以下か確かめる
  3. 対応する画像を小さな別名ファイルとして用意し、再度追加する
  4. 同じ条件でも追加ボタンが使えないなら、アカウントやグループの背景設定を管理者に確認してもらう

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますログアウト、再インストール、アカウント削除の前に、引き継ぎ情報、下書き、トーク履歴、二段階認証を確認してください。

背景に勤務先の資料や他人の顔を無断で使わないでください。画像変換時には元データを残し、非公式サイトへ機密画像をアップロードしないでください。 設定を一度に複数変えず、各手順の結果を確かめてから次へ進んでください。
