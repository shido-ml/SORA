スプレッドシートのピボット表に追加行が出ないとき

元の表へ行を追加したのに集計が増えない。ピボット表の参照範囲に追加行が含まれるか確認します。フィルタ条件も別に見ます。

公開・更新：2026年10月28日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

ピボット表の参照範囲に追加行が含まれるか確認します。フィルタ条件も別に見ます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. ピボット表の下にある編集ボタンからピボットテーブルエディタを開きます。
  2. 『データ範囲を選択』で元データの範囲と追加行の位置を比べます。
  3. 追加行が範囲外なら、必要な行を含む範囲へ変更します。

症状を切り分ける

Googleは参照元のセルが変更されればピボット表は更新されると説明しています。したがって手動の『更新』ボタンだけを探す前に、追加行が参照範囲へ入っているかとフィルタで隠れていないかを区別します。元表の行番号も控えます。

「元の表へ行を追加したのに集計が増えない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • ブラウザ版とアプリ版の両方で起きるか
  • 別アカウントや別端末では正常に利用できるか
  • 保存容量、同期状態、Google側の障害情報に異常がないか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 新しい行が参照範囲の外
  • 値フィルタが新項目を除外
  • 追加したつもりのセルが別シートや別表にある

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. ピボット表の下にある編集ボタンからピボットテーブルエディタを開きます。
  2. 『データ範囲を選択』で元データの範囲と追加行の位置を比べます。
  3. 追加行が範囲外なら、必要な行を含む範囲へ変更します。
  4. 値によるフィルタがある場合は新しい値が除外されていないか確認します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますアカウント削除やデータ削除の前に、同期先、ゴミ箱、バックアップ、復元期限を確認してください。

集計値を直接書き換えると元データとの関係が崩れます。範囲を広げる時は無関係な表や見出しを混ぜず、変更前の範囲を控えておきます。共有シートでは他の利用者の集計への影響も確認してください。
