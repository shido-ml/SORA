Googleカレンダーの予定の詳細を共有相手に隠したいとき

共有カレンダーで予定名や内容を見せず時間だけ確保したい。対象の予定の公開範囲を確認し、必要な予定だけ『非公開』に設定します。

公開・更新：2026年10月29日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

対象の予定の公開範囲を確認し、必要な予定だけ『非公開』に設定します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. PC版Googleカレンダーで対象の予定を開き、編集画面へ進みます。
  2. 公開範囲を確認し、詳細を隠したい予定だけ『非公開』を選びます。
  3. 保存後、共有相手が予定をどう見られるか、権限の違う相手で確認します。

症状を切り分ける

自分のカレンダーに予定が表示されない同期問題ではなく、他の人から予定の詳細がどう見えるかという公開範囲の問題です。まず対象予定の公開範囲を確かめ、共有カレンダー全体の設定と組み合わせて確認します。権限を持つ相手には見え方が異なる場合があります。

「共有カレンダーで予定名や内容を見せず時間だけ確保したい」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • ブラウザ版とアプリ版の両方で起きるか
  • 別アカウントや別端末では正常に利用できるか
  • 保存容量、同期状態、Google側の障害情報に異常がないか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 予定ごとの公開範囲が『公開』または既定値
  • カレンダー全体の共有権限が想定より広い
  • 編集した予定と共有された予定が違う

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. PC版Googleカレンダーで対象の予定を開き、編集画面へ進みます。
  2. 公開範囲を確認し、詳細を隠したい予定だけ『非公開』を選びます。
  3. 保存後、共有相手が予定をどう見られるか、権限の違う相手で確認します。
  4. カレンダー全体の共有権限も確認し、公開設定が意図と合うか見直します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますアカウント削除やデータ削除の前に、同期先、ゴミ箱、バックアップ、復元期限を確認してください。

『非公開』の指定だけで予定の存在そのものやすべての情報を完全に隠せるとは限りません。機密の予定を入れる前にカレンダーの共有範囲と相手の権限を確認し、必要なら別の非共有カレンダーを使います。
