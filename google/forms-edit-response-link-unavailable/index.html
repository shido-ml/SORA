Googleフォームで送信後に回答を編集できないとき

提出済みの回答を直すリンクが見つからない。フォーム所有者の回答編集設定と回答者に表示されるリンクを確認します。

公開・更新：2026年10月29日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

フォーム所有者の回答編集設定と回答者に表示されるリンクを確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 回答者は送信完了画面や控えのメールに編集リンクがあるか確認します。
  2. 所有者はフォームの『設定』から『回答』を開き、『回答の編集を許可』の状態を確認します。
  3. 設定が有効ならテスト回答で送信後の編集リンクを確認します。

症状を切り分ける

回答者の端末に編集ボタンが出ないとき、まず編集を許可するかはフォームの所有者側の設定で決まることを確認します。回答受付が停止している問題とは異なり、既に送信した回答の再編集可否を調べます。送信後の画面と控えの有無を分けて記録します。

「提出済みの回答を直すリンクが見つからない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • ブラウザ版とアプリ版の両方で起きるか
  • 別アカウントや別端末では正常に利用できるか
  • 保存容量、同期状態、Google側の障害情報に異常がないか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 所有者が回答の編集を許可していない
  • 送信完了画面を閉じてリンクを控えていない
  • 別のフォームやアカウントの回答を探している

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 回答者は送信完了画面や控えのメールに編集リンクがあるか確認します。
  2. 所有者はフォームの『設定』から『回答』を開き、『回答の編集を許可』の状態を確認します。
  3. 設定が有効ならテスト回答で送信後の編集リンクを確認します。
  4. 設定が無効で提出済みの回答を直せない場合は、所有者へ修正方法を問い合わせます。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますアカウント削除やデータ削除の前に、同期先、ゴミ箱、バックアップ、復元期限を確認してください。

回答を修正するために無断で二重送信すると集計が重複します。試験回答は所有者の確認用フォームで行い、本人確認や提出期限があるフォームでは正式な修正方法を所有者に尋ねてください。
