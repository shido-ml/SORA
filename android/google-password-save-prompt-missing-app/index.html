Androidで特定アプリのパスワード保存提案が出ないとき

他のアプリでは保存できるのに一つのアプリだけ提案されない。保存を拒否したアプリ一覧と自動入力設定を確認します。以前に保存を拒否したアプリの一覧も調べます。

公開・更新：2026年10月31日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

保存を拒否したアプリ一覧と自動入力設定を確認します。以前に保存を拒否したアプリの一覧も調べます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Googleパスワードマネージャーの設定を開き、パスワード保存の提案が有効か確認します。
  2. 「保存しない」または拒否したサイトとアプリの一覧に対象があるか調べます。
  3. 対象があれば内容を確認して一覧から外し、次の正規ログイン時に提案が出るか試します。

症状を切り分ける

Googleのパスワードマネージャーには保存提案を拒否したサイトやアプリの一覧があり、特定アプリだけ提案がない場合の確認点です。全アプリで起きるなら端末全体の提案設定を優先します。ログイン画面に保存提案が出ないことと、保存済みパスワードでログインできないことは別の症状です。

「他のアプリでは保存できるのに一つのアプリだけ提案されない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 特定のアプリだけか、端末全体で起きるか
  • Wi-Fiとモバイル通信を切り替えると変化するか
  • OS更新、アプリ更新、設定変更の直後から始まったか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 以前にそのアプリで保存を拒否した
  • 全体の保存提案設定がオフ
  • 自動入力サービスがGoogle以外に切り替わっている

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Googleパスワードマネージャーの設定を開き、パスワード保存の提案が有効か確認します。
  2. 「保存しない」または拒否したサイトとアプリの一覧に対象があるか調べます。
  3. 対象があれば内容を確認して一覧から外し、次の正規ログイン時に提案が出るか試します。
  4. 他のアプリでも提案されない場合は端末の自動入力サービス設定を確認します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行います端末の初期化、アプリのデータ消去、アカウント削除は保存内容に影響します。同期とバックアップを確認してから行ってください。

保存提案の確認のため、他人にパスワードを見せたりメモへ平文で貼ったりしないでください。フィッシング画面で試さず、公式アプリの正規ログイン画面を使います。会社の端末では組織指定のパスワード管理方針を優先してください。
