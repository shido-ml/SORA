AndroidスマホをPCにUSB接続してもファイル転送できない

AndroidをWindowsやMacへUSB接続しても充電だけになる、フォルダーが表示されないときに、ケーブルとUSB用途を確認する手順です。

公開・更新：2026年8月16日読了目安：4分確認済み：公式サポート情報
結論

データ通信対応のUSBケーブルでスマホを直接PCへ接続し、画面ロックを解除します。USB通知を開いて用途を「ファイル転送／Android Auto」に変更し、別ポートでも試してください。

先に確認してください接続中にケーブルを抜く前に転送を終え、破損した端子へ無理に差し込まないでください。

まず試すこと

  1. スマホのロックを解除し、USB接続の通知をタップして「ファイル転送」を選ぶ。
  2. 充電専用ケーブルではなくデータ対応ケーブルへ替え、USBハブを外してPC本体の別ポートへ直接接続します。
  3. ロック解除後にUSB用途を変更します。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • USB通知にファイル転送の選択肢が出るか
  • 別のデータ対応ケーブルで変わるか
  • 同じPCの別ポート・別PCで認識するか
  • 端末の充電口に異物やぐらつきがないか

考えられる原因

この症状で最初に疑うのは、充電専用・断線ケーブル、USB用途が充電のみ、画面ロック、PCドライバー、端子の汚れや故障です。加えて、次の原因も順番に確認します。

  • 充電専用または劣化したケーブル
  • USBモードが充電のみに固定
  • MTPドライバーの停止
  • 端子・ハブ・PCポートの問題

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. スマホのロックを解除し、USB接続の通知をタップして「ファイル転送」を選ぶ。
  2. 充電専用ケーブルではなくデータ対応ケーブルへ替え、USBハブを外してPC本体の別ポートへ直接接続します。
  3. ロック解除後にUSB用途を変更します。
  4. ケーブルとPCポートを替えます。
  5. PCを再起動しOS更新を適用します。
  6. Windowsのデバイスマネージャーで警告を確認します。

解決しない場合

複数のデータケーブルとPCで認識せず、端子が緩い・充電も途切れる場合は端末メーカーへ点検を依頼します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
