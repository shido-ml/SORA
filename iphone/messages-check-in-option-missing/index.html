iPhoneのメッセージで『到着確認』が出ないとき

家族に到着を知らせるチェックインを作成できない。送信者と受信者のiOS、メッセージの操作場所、会話相手を確認します。

公開・更新：2026年10月29日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

送信者と受信者のiOS、メッセージの操作場所、会話相手を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 送信側と受信側のiPhoneが機能に対応するiOS 17以降か確認します。
  2. メッセージで対象の相手との会話を開き、入力欄横の『＋』を押します。
  3. 『その他』にある『到着確認』を探し、予定や共有内容を確認してから送ります。

症状を切り分ける

到着確認は相手に現在地を常時共有する『探す』の設定とは異なり、予定した到着の確認を送るメッセージ機能です。表示されないときは位置情報の精度だけを疑う前に、両側のiOSとメッセージの追加メニューを確認します。

「家族に到着を知らせるチェックインを作成できない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 同じApple Accountの別端末でも起きるか、iPhoneだけで起きるか
  • Wi-Fiとモバイル通信を切り替えると症状が変わるか
  • iOS更新、空き容量、関連する設定変更のあとに始まったか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 送信側または受信側のiOSが対応版より古い
  • メッセージの追加メニューを開いていない
  • 機能に対応しない会話やアカウントを選んでいる

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 送信側と受信側のiPhoneが機能に対応するiOS 17以降か確認します。
  2. メッセージで対象の相手との会話を開き、入力欄横の『＋』を押します。
  3. 『その他』にある『到着確認』を探し、予定や共有内容を確認してから送ります。
  4. 出ない場合は双方のiOSと会話相手を記録し、Appleの案内と照合します。

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますサインアウトや初期化を行う前に、必要な写真・連絡先などの保存状況と復旧手段を確認してください。共有や支払いに関する設定は、本人のアカウントと端末だけで操作してください。

到着確認には予定どおり着けなかったときの位置や端末情報の共有設定があります。送信前に共有する情報の範囲を読み、相手の同意と安全を確認してください。緊急連絡の唯一の手段として頼らないでください。
