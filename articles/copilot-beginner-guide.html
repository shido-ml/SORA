Microsoft Copilotの使い方｜できることを初心者向けに解説

公開日：2026年8月4日更新日：2026年8月4日目安：6分

Microsoft Copilotは、会話形式で質問、文章作成、アイデア出しなどを支援するAIです。一般向けCopilotとMicrosoft 365内のCopilotでは利用できる機能や契約が異なるため、使っている画面とプランを確認しましょう。

基本手順

  1. Microsoft Copilotを開き、目的を一文で入力する
  2. 必要な条件と出力形式を追加する
  3. 回答の根拠や代案を質問する
  4. 重要な内容は一次情報へ戻って確認する
広告

コピペ用プロンプト

角括弧の部分を自分の情報に差し替えて使ってください。入力前に個人情報や機密情報が含まれていないか確認します。

町内会のお知らせ文を作ってください。 内容：公園清掃、8月20日午前8時開始、雨天中止、軍手持参。 対象：幅広い年代。 条件：見出し付き、250文字以内、柔らかく分かりやすい日本語。

失敗を減らすポイント

  • 一般向けCopilotとMicrosoft 365 Copilotを混同しない
  • 仕事で使う場合は所属組織の契約とデータ保護方針を確認する
  • 生成文の事実、固有名詞、日時を確認する

よくある質問

ExcelやWordでも使えますか？

Microsoft 365 Copilotは対象のWord、Excel、PowerPoint等で支援します。利用には対象プラン等の条件があります。

無料版と有料版の違いは？

機能や上限が更新されるため、Microsoftの現在の料金・機能ページで確認してください。

重要
生成AIの機能、料金、利用上限、名称は変更される場合があります。契約、法律、医療、金融、セキュリティに関わる判断は、AIの回答だけで決めず、公式情報や専門家を確認してください。
