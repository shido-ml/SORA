Macのスクリーンショットが見つからないときの確認手順

撮影後の画像が見つからないとき、ショートカット、保存先設定、クリップボードへの保存を切り分ける。

公開・更新：2026年10月22日読了目安：5分確認済み：Apple Macユーザガイド：スクリーンショットを撮影する
結論

Shift＋Command＋5でスクリーンショットのオプションを開き、「保存先」を確認します。保存先がデスクトップ以外ならその場所を探し、Controlキーを併用した撮影ならファイルではなくクリップボードに入っている可能性を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. Shift＋Command＋5でスクリーンショットのツールバーを開き、「オプション」の「保存先」を読む
  2. 指定されたフォルダをFinderで開き、撮影時刻やスクリーンショットのファイル名で探す
  3. Shift＋Command＋3で試し撮りし、画面隅のサムネイルと保存先を確認する

症状を切り分ける

撮影直後に右下へサムネイルが出るか、Finderにファイルが増えるかを別々に確認します。「保存先」の設定は次回以降の撮影先を示すので、過去の画像も必ずそこにあるとは限りません。日時を絞って検索し、画面収録の動画とスクリーンショットのPNGを取り違えていないかも見ます。

「Macで撮ったスクリーンショットの保存先が分からない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザー、別の接続先、セーフモードでも再現するか
  • macOS更新や周辺機器の接続後から始まったか
  • 電源、空き容量、ネットワークのどこに変化があるか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 保存先がデスクトップから別のフォルダやアプリに変更されている
  • Controlキーを併用し、画像をファイルではなくクリップボードに保存した
  • 撮影に失敗した、またはサムネイル表示を保存完了と取り違えた

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. Shift＋Command＋5でスクリーンショットのツールバーを開き、「オプション」の「保存先」を読む
  2. 指定されたフォルダをFinderで開き、撮影時刻やスクリーンショットのファイル名で探す
  3. Shift＋Command＋3で試し撮りし、画面隅のサムネイルと保存先を確認する
  4. Controlキーを併用していた場合は、画像編集アプリなどに貼り付けられるか確認する

解決しない場合

試し撮りでもファイルもクリップボードも確認できない場合は、使用したキー操作、保存先、macOS版を控えてAppleに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますディスク消去、macOS再インストール、アカウント削除は最後の手段です。Time Machineなどのバックアップを先に確認してください。

保存先を変える前に現在の設定を控えてください。クリップボードだけに入った画像は別の内容をコピーすると失われる可能性があるため、必要な画像は貼り付けて保存します。重要な記録なら撮影後に実際のファイルを開いて確認してください。
