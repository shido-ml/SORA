MacのプレビューでPDFを印刷できないとき

プレビューでPDFは開けるが印刷が制限され、他の文書は印刷できる。PDFの所有者が設定した印刷権限を確認し、許可が必要なら所有者に依頼します。

公開・更新：2026年11月6日読了目安：4分確認済み：製品提供元の公式ヘルプ
結論

PDFの所有者が設定した印刷権限を確認し、許可が必要なら所有者に依頼します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 同じプリンターで別のPDFを印刷できるか確かめ、機器の障害と区別する
  2. 対象PDFをプレビューで開き、印刷や編集の制限に関する表示を確認する
  3. 正当な所有者ならプレビューの権限設定と所有者パスワードを確認する

症状を切り分ける

他のPDFが印刷できるならプリンター全体をリセットしません。対象文書の権限表示を確認し、印刷不可が文書固有かを切り分けます。 変更前後の表示を同じ端末・同じアカウントで比較し、どの条件でだけ再現するか記録します。これにより設定の問題と別の症状を取り違えずに済みます。

「プレビューでPDFは開けるが印刷が制限され、他の文書は印刷できる」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別のユーザー、別の接続先、セーフモードでも再現するか
  • macOS更新や周辺機器の接続後から始まったか
  • 電源、空き容量、ネットワークのどこに変化があるか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • PDFの所有者パスワードで印刷が制限
  • 閲覧パスワードと所有者パスワードを混同
  • プリンターの問題と文書固有の制限を混同

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 同じプリンターで別のPDFを印刷できるか確かめ、機器の障害と区別する
  2. 対象PDFをプレビューで開き、印刷や編集の制限に関する表示を確認する
  3. 正当な所有者ならプレビューの権限設定と所有者パスワードを確認する
  4. 共有されたPDFなら所有者へ印刷可能な版の提供や権限変更を依頼する

解決しない場合

各設定と表示された文言を記録しても改善しない場合は、対象サービスの公式サポートに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますディスク消去、macOS再インストール、アカウント削除は最後の手段です。Time Machineなどのバックアップを先に確認してください。

所有者の許可なく制限を解除する手段は案内しません。業務文書や契約書は配布条件を守り、印刷が必要な理由を所有者へ伝えてください。 設定を一度に複数変えず、各手順の結果を確かめてから次へ進んでください。
