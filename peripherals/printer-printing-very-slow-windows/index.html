Windowsでプリンターの印刷開始や出力が遅いときの確認手順

印刷はできるが一枚出るまで長く待たされる。印刷品質、接続方式、画像の大きさを比べ、故障やキューの完全停止とは分けて調べます。

公開・更新：2026年10月25日読了目安：4分確認済み：Microsoftサポート：印刷が遅い場合の確認
結論

印刷品質、接続方式、画像の大きさを比べ、故障やキューの完全停止とは分けて調べます。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 簡単な一ページと高解像度画像を含むページの印刷時間を比べます。
  2. プリンターの印刷設定で品質が必要以上に高くないか、用紙種類が実際の用紙と合うか確認します。
  3. Wi-Fi接続なら可能な範囲でUSBまたは有線接続と時間を比べます。

症状を切り分ける

印刷待ちジョブが削除できない問題とは異なり、最終的には出力されるが速度だけが遅い状態を対象にします。Microsoft公式案内では印刷品質と用紙設定、無線と有線の比較、画像の複雑さを確認します。簡単な一ページを基準にすれば、文書側の処理と接続側の遅延を分けられます。

「印刷はできるが一枚出るまで長く待たされる」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別の端子、ケーブル、PCでも同じ症状が起きるか
  • 本体の電源・表示・物理スイッチに異常がないか
  • OS標準機能とメーカーアプリのどちらでも再現するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 印刷品質が高く処理に時間がかかっている。
  • 無線接続の遅延が大きい。
  • 高解像度画像など印刷ジョブが複雑である。

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 簡単な一ページと高解像度画像を含むページの印刷時間を比べます。
  2. プリンターの印刷設定で品質が必要以上に高くないか、用紙種類が実際の用紙と合うか確認します。
  3. Wi-Fi接続なら可能な範囲でUSBまたは有線接続と時間を比べます。
  4. メーカーが案内するファームウェアとドライバーの更新情報を機種別に確認します。

解決しない場合

簡単な文書でも複数の接続方法で遅い場合は、機種、印刷時間、用紙と品質の設定、接続方法を記録してメーカーに相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますフォーマット、ファームウェア更新、ドライバー削除の前に、機器内のデータとメーカーの注意事項を確認してください。

印刷品質を下げると文字や写真の仕上がりが変わります。正式な書類は必要な品質を維持し、試し刷りだけで比較してください。ファームウェア更新はメーカーの機種別手順と電源条件を確認し、業務用プリンターでは管理者へ相談します。

プリンターの印刷待ちジョブを削除できない

設定のプリンターキューで全ジョブをキャンセルし、プリンターとPCを再起動します。残る場合はPrint Spoolerサービスを停止し、スプールフォルダー内の待機ファイルだけを削除してサービスを再開します。

対処手順を見る →

Windowsでプリンターがオフラインと表示される

PCとプリンターが同じネットワークに接続されているか確認し、両方を再起動します。その後、印刷キューの停止や「プリンターをオフラインで使用する」が有効になっていないかを確認します。

対処手順を見る →

Windowsで「プリンタードライバーは使用できません」と出る

Windows Updateとプリンターメーカー公式ドライバーを確認し、登録削除・再追加を行います。非公式ドライバーサイトは使いません。

対処手順を見る →

BluetoothキーボードがWindowsで反応しない

電池、入力切替、ペアリング、他端末への接続を確認し、登録を削除して再接続します。
