Windowsでプリンターがオフラインと表示される

電源が入っているプリンターがオフラインになるときに、Wi-Fi、印刷待ち、既定プリンター、オフライン設定を確認します。

公開・更新：2026年8月12日読了目安：4分確認済み：公式サポート情報
結論

PCとプリンターが同じネットワークに接続されているか確認し、両方を再起動します。その後、印刷キューの停止や「プリンターをオフラインで使用する」が有効になっていないかを確認します。

先に確認してください印刷キューを削除すると、送信済みで未印刷の文書は取り消されます。必要な文書を確認してから削除してください。

まず試すこと

  1. プリンター本体のエラー表示とWi-Fi接続先を確認し、PCと同じネットワークへ接続されているか確かめる。
  2. Windowsの「設定」→「Bluetoothとデバイス」→「プリンターとスキャナー」から対象を開き、印刷キューを確認して停止中のジョブを整理します。
  3. 未保存データを確認してPCと機器を再起動します。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • 機器本体にエラーや警告ランプがないか
  • PCと機器が同じ接続先・ネットワークにあるか
  • 別端子・別PCでは使えるか

考えられる原因

この症状で最初に疑うのは、別Wi-Fiへの接続、プリンターのスリープや通信停止、詰まった印刷ジョブ、オフライン使用設定です。加えて、次の原因も順番に確認します。

  • 電源、ケーブル、Wi-Fiなど物理・通信接続
  • 印刷キューや選択先などOS設定
  • ドライバー、ファームウェア、機器本体の問題

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. プリンター本体のエラー表示とWi-Fi接続先を確認し、PCと同じネットワークへ接続されているか確かめる。
  2. Windowsの「設定」→「Bluetoothとデバイス」→「プリンターとスキャナー」から対象を開き、印刷キューを確認して停止中のジョブを整理します。
  3. 未保存データを確認してPCと機器を再起動します。
  4. ケーブルまたはWi-Fi接続先を確認します。
  5. Windowsの機器一覧と待機中の処理を確認します。
  6. メーカー公式のドライバーとファームウェアを確認します。

解決しない場合

別のPCでも使えない、機器本体に解消しないエラーが出る、異臭や異常発熱がある場合は使用を止めてメーカーへ相談します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
