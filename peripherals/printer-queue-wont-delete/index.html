プリンターの印刷待ちジョブを削除できない

Windowsの印刷キューでジョブが削除中・エラーのまま残り、新しい印刷も進まないときにスプーラーを安全に復旧する方法です。

公開・更新：2026年8月16日読了目安：4分確認済み：公式サポート情報
結論

設定のプリンターキューで全ジョブをキャンセルし、プリンターとPCを再起動します。残る場合はPrint Spoolerサービスを停止し、スプールフォルダー内の待機ファイルだけを削除してサービスを再開します。

先に確認してくださいPRINTERSフォルダー以外のWindowsシステムファイルを削除しないでください。スプーラーを停止してから待機ファイルだけを削除します。

まず試すこと

  1. 設定の「Bluetoothとデバイス」→「プリンターとスキャナー」から対象プリンターのキューを開き、全件キャンセルする。
  2. services.mscでPrint Spoolerを停止し、C:\Windows\System32\spool\PRINTERS内のファイルを削除してからサービスを開始します。
  3. キューから全ジョブをキャンセルします。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • 1件だけか全ジョブか
  • プリンター本体に紙詰まり・エラーがないか
  • 別プリンターのキューを見ていないか
  • Print Spoolerサービスが実行中か

考えられる原因

この症状で最初に疑うのは、破損した印刷データ、プリンター応答停止、Print Spoolerの停止、ドライバー不整合です。加えて、次の原因も順番に確認します。

  • 印刷ジョブの破損
  • プリンター通信停止
  • スプーラーサービス不調
  • ドライバー・ポート設定の不整合

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. 設定の「Bluetoothとデバイス」→「プリンターとスキャナー」から対象プリンターのキューを開き、全件キャンセルする。
  2. services.mscでPrint Spoolerを停止し、C:\Windows\System32\spool\PRINTERS内のファイルを削除してからサービスを開始します。
  3. キューから全ジョブをキャンセルします。
  4. PCとプリンターを再起動します。
  5. スプーラーを再起動します。
  6. 残る場合だけスプールファイルを手順どおり消去します。

解決しない場合

ジョブがすぐ再生成される、スプーラーが開始できない場合はエラー番号を控え、プリンタードライバーをメーカー手順で修復します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
