Windowsでスキャナーを認識しない・スキャンできない

Windowsでスキャナーを認識しない・スキャンできないときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：5分確認済み：Microsoft / scanner manufacturer support
結論

本体接続、USB・ネットワーク、Windows Scan、WIA、メーカー公式ドライバーを確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. スキャナーの電源・エラー表示を確認し、USBは本体へ直接、ネットワーク型はPCと同じSSIDへ接続する
  2. 「設定→Bluetoothとデバイス→プリンターとスキャナー」とWindows Scanで機器が表示されるか確認する
  3. メーカー公式スキャンユーティリティで比較し、Windows Image Acquisition（WIA）サービスを再起動する

症状を切り分ける

「スキャナー Windows 認識しない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別の端子、ケーブル、PCでも同じ症状が起きるか
  • 本体の電源・表示・物理スイッチに異常がないか
  • OS標準機能とメーカーアプリのどちらでも再現するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 接続先・ネットワーク違い
  • WIA・ドライバー不調
  • ファイアウォール・本体故障

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. スキャナーの電源・エラー表示を確認し、USBは本体へ直接、ネットワーク型はPCと同じSSIDへ接続する
  2. 「設定→Bluetoothとデバイス→プリンターとスキャナー」とWindows Scanで機器が表示されるか確認する
  3. メーカー公式スキャンユーティリティで比較し、Windows Image Acquisition（WIA）サービスを再起動する
  4. Windowsとメーカー公式ドライバーを更新し、ファイアウォールを無効化せず公式アプリの許可だけ確認する

解決しない場合

本体単体テストも失敗する場合はメーカーへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますフォーマット、ファームウェア更新、ドライバー削除の前に、機器内のデータとメーカーの注意事項を確認してください。

Windowsでプリンターがオフラインと表示される

PCとプリンターが同じネットワークに接続されているか確認し、両方を再起動します。その後、印刷キューの停止や「プリンターをオフラインで使用する」が有効になっていないかを確認します。

WindowsでUSB機器が認識されない

USBハブを外してPC本体の別ポートへ直接接続し、別のPCでも認識するか確認します。機器自体かWindows側かを分けてから、デバイスマネージャーを確認してください。

対処手順を見る →

AndroidスマホをPCにUSB接続してもファイル転送できない

データ通信対応のUSBケーブルでスマホを直接PCへ接続し、画面ロックを解除します。USB通知を開いて用途を「ファイル転送／Android Auto」に変更し、別ポートでも試してください。

対処手順を見る →

BluetoothマウスがWindowsで動かない・反応しない

マウスの電池と電源を確認し、別端末へ自動接続されていないかを調べます。WindowsのBluetooth一覧で接続状態を確認し、必要なら登録を削除してペアリングし直します。
