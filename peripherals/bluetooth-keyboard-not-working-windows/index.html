BluetoothキーボードがWindowsで反応しない

BluetoothキーボードがWindowsで反応しないときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：Microsoft Support - Windows の Bluetooth の問題を解決する
結論

電池、入力切替、ペアリング、他端末への接続を確認し、登録を削除して再接続します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 新品または充電済み電池、電源スイッチ、Windows/Mac切替、接続チャンネルを確認する
  2. キーボードを説明書どおりペアリングモードにし、スマホなど他端末への自動接続を解除する
  3. Windowsの「設定→Bluetoothとデバイス」で既存登録を削除し、近くに置いて再ペアリングする

症状を切り分ける

「Bluetoothキーボード Windows 反応しない」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別の端子、ケーブル、PCでも同じ症状が起きるか
  • 本体の電源・表示・物理スイッチに異常がないか
  • OS標準機能とメーカーアプリのどちらでも再現するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • 電池・入力切替
  • 他端末への自動接続
  • Bluetoothドライバー・互換性

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 新品または充電済み電池、電源スイッチ、Windows/Mac切替、接続チャンネルを確認する
  2. キーボードを説明書どおりペアリングモードにし、スマホなど他端末への自動接続を解除する
  3. Windowsの「設定→Bluetoothとデバイス」で既存登録を削除し、近くに置いて再ペアリングする
  4. WindowsとBluetoothドライバーを更新し、別PCでも同じキーが反応しないか比較する

解決しない場合

別PCでも反応しなければキーボードメーカー、複数機器が不可ならPCメーカーへ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますフォーマット、ファームウェア更新、ドライバー削除の前に、機器内のデータとメーカーの注意事項を確認してください。
