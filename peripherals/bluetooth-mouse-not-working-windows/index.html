BluetoothマウスがWindowsで動かない・反応しない

Bluetoothマウスが接続済みなのに動かない、一覧に出ないときに、電池、ペアリング、別端末、Windows設定を切り分けます。

公開・更新：2026年8月14日読了目安：4分確認済み：公式サポート情報
結論

マウスの電池と電源を確認し、別端末へ自動接続されていないかを調べます。WindowsのBluetooth一覧で接続状態を確認し、必要なら登録を削除してペアリングし直します。

先に確認してくださいマウスが使えない場合はTab・矢印・Enterキーでも設定を操作できます。業務中のPCでは管理ポリシーがあるため、ドライバー削除前に管理者へ確認してください。

まず試すこと

  1. マウスの電池を交換または充電し、電源を入れ直して、底面ランプやペアリングボタンが反応するか確認する。
  2. 「設定」→「Bluetoothとデバイス」でマウスを一度削除し、マウスをペアリングモードにして「デバイスの追加」から登録し直します。
  3. 未保存データを確認してPCと機器を再起動します。

症状を切り分ける

設定をまとめて変える前に、問題が起きる範囲を確認します。範囲が分かると、不要な初期化やデータ削除を避けられます。

  • 機器本体にエラーや警告ランプがないか
  • PCと機器が同じ接続先・ネットワークにあるか
  • 別端子・別PCでは使えるか

考えられる原因

この症状で最初に疑うのは、電池切れ、別PCへの接続、ペアリング情報の不整合、Bluetoothのオフや電波干渉、Windowsドライバー、マウス本体の故障です。加えて、次の原因も順番に確認します。

  • 電源、ケーブル、Wi-Fiなど物理・通信接続
  • 印刷キューや選択先などOS設定
  • ドライバー、ファームウェア、機器本体の問題

解決手順

途中で改善したら、残りの操作は行わなくて構いません。変更した設定は必要に応じて元へ戻してください。

  1. マウスの電池を交換または充電し、電源を入れ直して、底面ランプやペアリングボタンが反応するか確認する。
  2. 「設定」→「Bluetoothとデバイス」でマウスを一度削除し、マウスをペアリングモードにして「デバイスの追加」から登録し直します。
  3. 未保存データを確認してPCと機器を再起動します。
  4. ケーブルまたはWi-Fi接続先を確認します。
  5. Windowsの機器一覧と待機中の処理を確認します。
  6. メーカー公式のドライバーとファームウェアを確認します。

解決しない場合

別のPCでも使えない、機器本体に解消しないエラーが出る、異臭や異常発熱がある場合は使用を止めてメーカーへ相談します。

相談前に、症状が始まった時期、再現する操作、表示されたエラー、試した手順をメモしておくと診断が早くなります。

注意点

削除・初期化・再インストールは最後に保存済みデータ、ログイン状態、端末設定が消える操作があります。同期やバックアップ、復旧に必要なアカウント情報を確認してから進めてください。
