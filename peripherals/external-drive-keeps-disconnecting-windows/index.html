外付けHDD・SSDがWindowsで頻繁に切断される

外付けHDD・SSDがWindowsで頻繁に切断されるときに、原因を切り分け、データを消さずに試せる対処手順を解説します。

公開・更新：2026年8月23日読了目安：4分確認済み：Microsoft / drive manufacturer support
結論

重要データを先に退避し、ケーブル、電源、USBポート、省電力、メーカー診断を確認します。

まず試すこと

設定をまとめて変えず、次の操作を1つずつ試してください。各手順のあとに症状を確認すると、原因を絞りやすくなります。

  1. 認識している間に重要データを別の正常な媒体へコピーし、移動や最適化はしない
  2. USBハブを外し、短い対応ケーブル・PC本体の別ポート・付属ACアダプターで比較する
  3. 「デバイスマネージャー→USBルートハブ」の電源管理とWindowsの電源プランを確認する

症状を切り分ける

「外付けHDD SSD 勝手に切れる Windows」の範囲を先に確認します。端末、接続先、アカウントなど条件を1つだけ変えて比べると、不要な削除や初期化を避けられます。

  • 別の端子、ケーブル、PCでも同じ症状が起きるか
  • 本体の電源・表示・物理スイッチに異常がないか
  • OS標準機能とメーカーアプリのどちらでも再現するか

考えられる原因

表示や発生条件が次のどれに近いかを確認してください。複数が重なる場合もあるため、決めつけず上から順に切り分けます。

  • ケーブル・電力不足
  • USB省電力
  • ドライブ劣化

解決手順

途中で改善したら残りの操作は不要です。改善しなかった手順と画面表示をメモしておくと、次の判断や相談がしやすくなります。

  1. 認識している間に重要データを別の正常な媒体へコピーし、移動や最適化はしない
  2. USBハブを外し、短い対応ケーブル・PC本体の別ポート・付属ACアダプターで比較する
  3. 「デバイスマネージャー→USBルートハブ」の電源管理とWindowsの電源プランを確認する
  4. メーカー公式診断でSMARTを確認し、異音・再接続反復・警告があれば診断を打ち切る

解決しない場合

異音、認識反復、SMART警告があれば通電を減らしメーカー・復旧業者へ相談します。

相談時は、症状が始まった日時、再現条件、表示された文言、試した手順と結果を伝えてください。

注意点

削除や初期化は最後に行いますフォーマット、ファームウェア更新、ドライバー削除の前に、機器内のデータとメーカーの注意事項を確認してください。

Macで外付けSSD・HDDがFinderに表示されない

Finderのサイドバー表示を確認した後、ディスクユーティリティの「すべてのデバイスを表示」で機器自体が認識されているかを調べます。認識済みならマウント、未認識なら接続を切り分けます。

対処手順を見る →

USBメモリに「フォーマットする必要があります」と表示される

必要なデータがあるなら「キャンセル」を選び、フォーマットしないでください。別USBポートと別PCで読み取りを確認し、ディスクの管理で容量・ドライブ文字・ファイルシステム表示を記録します。

対処手順を見る →

WindowsでUSB機器が認識されない

USBハブを外してPC本体の別ポートへ直接接続し、別のPCでも認識するか確認します。機器自体かWindows側かを分けてから、デバイスマネージャーを確認してください。

対処手順を見る →

BluetoothマウスがWindowsで動かない・反応しない

マウスの電池と電源を確認し、別端末へ自動接続されていないかを調べます。WindowsのBluetooth一覧で接続状態を確認し、必要なら登録を削除してペアリングし直します。
